# D2 悬停检测

| 日期 | 结论 |
| ---- | ---- |
| 20261116 | 初稿（P4：指针跟踪、当前宿主、译文归位、节流） |
| 20261116 | 宿主改为任意文字标签：渲染层按宿主计算样式决定换行/空格；D2 只负责把指针元素交给 D1 解析 |

源码：`src/content/hover.js`。

## 1. 职责与边界

- 记录鼠标位置，解析「当前宿主」供快捷键使用。
- 指针落在译文上时，归到该译文所属的原文宿主。
- 不做自动翻译：只有后台命令到达才触发请求。
- 不发请求、不渲染、不写 storage；解析交给 D1，渲染与请求交给 D5。

## 2. 事件与节流

- 监听 `pointermove`（`passive`）、`pointerleave` 与 `pointerout`（无 `relatedTarget` 表示离开窗口）。
- `pointermove` 只记录坐标与事件目标；按 80 毫秒（`DISPLAY_UPDATE_THROTTLE_MS`）节流解析一次，避免每次移动都走 `closest` 与 `getComputedStyle`。
- 命令到达时 `getCurrentHost()` 按最新坐标立即复核一次，避免「移动后 80 毫秒内按快捷键」拿到旧宿主。
- `pointerleave` / 离开窗口时清空坐标、当前宿主与节流计时器。
- `start()` / `stop()` 幂等；重复 `start()` 不会重复监听。

## 3. 位置复核与归位

```text
getCurrentHost():
  若没有指针记录 → null
  优先 elementFromPoint(x, y)；不可用或返回空时退回最近一次事件目标
  交给 D1 resolveAt(element)
    ├─ 元素在译文容器内 → data-st-for → 宿主
    ├─ 元素在表单值控件 / 可编辑区内 → null
    └─ 其它 → 向上找最近的文字宿主（任意标签，含 button、code 等）
```

- 页面滚动、缩放后不缓存旧宿主：下一次命令按当前坐标重新解析。
- `elementFromPoint` 可注入，便于单元测试；真实页面使用 `document.elementFromPoint`。
- 指针在页面外、空白、纯数字/符号、表单值控件、可编辑区、折叠内容上时返回空；按钮、链接、代码等文字正常解析为宿主。

## 4. 接口

```js
const hover = createHoverTracker({
  resolve: resolveAt,                    // 可注入，测试用
  getElementAt: (x, y) => Element|null,  // 可注入，默认 elementFromPoint
  schedule, cancel,                      // 可注入的定时器
});
hover.start();
hover.getCurrentHost(); // Element | null
hover.stop();
```

## 5. 日志

| 事件 | 级别 | 内容 |
| ---- | ---- | ---- |
| `hover.target` | debug | 当前宿主 id 变化；没有宿主时记 `null` |

- 只记 `hostId` 或 `null`，不记页面文本、坐标与完整 URL。
- 同一宿主连续移动不重复记录。

## 6. 边界情况

- 未调用 `start()` 或 Node 环境没有 `document` 时：`getCurrentHost()` 返回 `null`，不抛错。
- `elementFromPoint` 抛错：退回最近一次事件目标。
- 指针在 iframe / Shadow DOM 内：P4 不处理，返回空或落到宿主页面元素。
- 页面在两次事件之间被改写：命令到达时重新解析，旧引用自然失效。

## 7. 与快捷键的关系

- Ctrl 单键手势由 `src/content/index.js` 的 `installCtrlTap` 处理，触发时读取本模块的 `getCurrentHost()`；D2 本身不监听键盘。
- 备用键 `Ctrl+Shift+Y` 经 A1 → `ST_TOGGLE` → 页面入口 → D2 取当前宿主，与 Ctrl 单键共用同一个 `getCurrentHost()`。
