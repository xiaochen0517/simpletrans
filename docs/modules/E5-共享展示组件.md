# E5 共享展示组件

| 日期 | 结论 |
| ---- | ---- |
| 20261119 | 初稿：UI 与样式统一规范化落地后建立；弹窗与设置页共用 daisyUI 展示组件 |
| 20261120 | daisyUI 展示组件 → HyperUI 复制式组件；新增 `Button` / `Toggle`；颜色改用 Tailwind 调色板，深色用 `data-theme` + `dark:` 变体；Neobrutalism 只用于关于页 |

本文记录 E5 共享展示组件的职责、API、样式规则与可访问性约定。模块划分与依赖见 [项目架构](../项目架构.md) 4.6 与 5.1；下拉与页面交互见 [B1-状态显示](./B1-状态显示.md)、[C-设置页](./C-设置页.md)。

## 1. 职责与边界

- 为工具栏弹窗（B）与设置页（C）提供统一的 HyperUI 展示组件，保证按钮、开关、下拉、提示、字段与状态徽标的行为、语义和视觉一致。
- 只组合 HyperUI 复制式标记与 Tailwind 布局类；不携带自定义 CSS，不定义颜色、圆角、阴影或动画。
- 不读写 `chrome.*`、不依赖 E1/E2/E3/E4，也不依赖 A/B/C/D。
- 不进入 content 产物；页面注入不引用 React 组件。
- Neobrutalism 不进入 E5：它只属于设置页关于分区（`src/options/sections/about.jsx`）。

## 2. 组件

### 2.1 Button

源码：`src/shared/ui/button.jsx`

用途：产品内所有普通操作按钮（命令、保存、刷新、复制、危险确认等）。

| 参数 | 类型 | 说明 |
| ---- | ---- | ---- |
| `variant` | `'primary' \| 'secondary' \| 'ghost' \| 'danger' \| 'warning'` | 默认 `secondary`；主操作 `primary`，危险操作 `danger` |
| `size` | `'xs' \| 'sm' \| 'md'` | 默认 `sm`；密集操作 `xs` |
| `busy` | `boolean` | 显示 `LoaderCircle` + `animate-spin`，设置 `aria-busy` 并禁用 |
| `iconOnly` | `boolean` | 方形内边距，必须同时提供 `aria-label` |
| `className` | `string` | 追加布局类 |
| 其它 | - | 透传 `type`、`onClick`、`disabled`、`title`、`aria-*`；默认 `type="button"` |

样式：

- 主按钮：`bg-indigo-600 text-white hover:bg-indigo-700`（dark `bg-indigo-500` / `hover:bg-indigo-400`）。
- 次按钮：白底 + `border-gray-300` + `hover:bg-gray-50`（dark `bg-gray-900` / `border-gray-700` / `hover:bg-gray-800`）。
- 幽灵：透明底 + `hover:bg-gray-100`（dark `hover:bg-gray-800`）。
- 危险：`bg-red-600 text-white hover:bg-red-700`；警告：`bg-amber-500 text-gray-900`。
- 焦点：`focus-visible:ring-2 focus-visible:ring-indigo-500 focus-visible:ring-offset-2`；禁用 `opacity-50` + `cursor-not-allowed`。

### 2.2 Toggle

源码：`src/shared/ui/toggle.jsx`

用途：设置页与实例卡片中的开关（启用扩展、缓存、stream、thinking、参数开关等）。

| 参数 | 类型 | 说明 |
| ---- | ---- | ---- |
| `checked` | `boolean` | 当前状态 |
| `onChange` | `(checked: boolean) => void` | 变更回调 |
| `disabled` | `boolean` | 禁用 |
| `ariaLabel` | `string` | 无可见 label 时必填 |
| `ariaDescribedBy` | `string` | 关联帮助/错误 |
| `size` | `'sm' \| 'md'` | 默认 `sm` |
| `className` | `string` | 追加布局类 |

结构：`label`（轨道）> `input[type=checkbox].sr-only` + `span`（滑块）。开启轨道 `bg-indigo-600`，关闭 `bg-gray-300`（dark `bg-gray-700`）；滑块白底；`focus-within` 显示焦点环。

### 2.3 Select

源码：`src/shared/ui/select.jsx`

用途：产品内单选下拉（翻译方式、语言、日志级别、测试实例、认证方式、思考强度等）。

| 参数 | 类型 | 说明 |
| ---- | ---- | ---- |
| `id` | `string` | 容器 id（可选，默认 `useId`） |
| `value` | `string` | 当前值 |
| `options` | `Array<{ value, label, detail?, disabled? }>` | `label` 第一行，`detail` 第二行 |
| `onChange` | `(value: string) => void` | 选择回调 |
| `placeholder` | `string` | 空值/空列表文案，默认「请选择」 |
| `ariaLabel` | `string` | 触发器的可访问名称（必填） |
| `ariaDescribedBy` | `string` | 关联帮助/错误文字 |
| `disabled` | `boolean` | 禁用 |
| `loading` | `boolean` | 加载中，触发器显示 spinner |
| `className` | `string` | 追加布局类 |

结构：`details[data-slot="select"]` + `summary[data-slot="select-trigger"]` + `ul[role="radiogroup"][data-slot="select-panel"]`；触发器右侧 `ChevronDown`，展开时旋转。选项为 `button[role="radio"]`，`data-value` 与 `data-active` 保留。

外观：

- 触发器：白底、`border-gray-300`、`rounded-lg`、`px-3 py-2`、`text-sm`、`shadow-sm`；dark `bg-gray-900` / `border-gray-700`。
- 面板：`absolute z-30 max-h-72 overflow-y-auto rounded-lg border border-gray-200 bg-white p-1 shadow-lg`；靠近视口底部时向上展开。
- 选项：两行；选中 `bg-indigo-50 text-indigo-700` + `Check`；hover `bg-gray-100`；dark 对应 `bg-indigo-950/40` / `text-indigo-200` / `hover:bg-gray-800`。

状态：

| 状态 | 表现 |
| ---- | ---- |
| 展开 | 面板宽度与触发器一致，`max-h-72` 滚动；当前项可聚焦 |
| 选择 | 更新值、关闭面板、焦点回到触发器 |
| 禁用/加载 | `aria-disabled`，阻止展开 |
| 空列表 | 面板显示占位文字 |
| 无匹配值 | 触发器显示占位文字 |

可访问性：

- `summary` 使用原生 disclosure 语义，Enter/Space 展开；`aria-haspopup`、`aria-expanded`。
- 面板为 `role="radiogroup"`，选项为 `role="radio"` + `aria-checked`。
- 键盘：方向键循环、Home/End、Enter/Space 选择、Esc 关闭并回到触发器、Tab 关闭。
- 点击面板外部关闭；焦点移出面板时关闭。

### 2.4 Notice

源码：`src/shared/ui/notice.jsx`

| 参数 | 说明 |
| ---- | ---- |
| `tone` | `success` / `error` / `warning` / `info` |
| `children` | 提示文字 |
| `icon` | 可选图标，默认按 `tone` 选择 lucide 图标 |
| `className` | 追加布局类 |

输出：`flex items-start gap-2 rounded-lg border p-3 text-sm` + 语义色；`error` 用 `role="alert"`，其它用 `role="status"` + `aria-live="polite"`。颜色：

- 成功 `border-green-500 bg-green-50 text-green-800`；
- 错误 `border-red-500 bg-red-50 text-red-800`；
- 警告 `border-amber-500 bg-amber-50 text-amber-800`；
- 信息 `border-blue-500 bg-blue-50 text-blue-800`；
- dark 使用对应 `*-950/40` 浅底与 `*-200` 文字。

### 2.5 Field

源码：`src/shared/ui/field.jsx`

- 组合「标签 + 控件 + 错误 + 帮助」，错误 `role="alert"`，帮助/错误 id 分别为 `${id}-error` / `${id}-help`。
- 标签 `text-xs font-semibold text-gray-700`（dark `text-gray-300`）；帮助 `text-gray-500`（dark `text-gray-400`）；错误 `text-red-600`（dark `text-red-400`）。
- 导出 `describedBy(id, { help, error })`，供控件生成 `aria-describedby`。
- 容器带 `data-field={id}`，供测试与定位使用。

### 2.6 StatusBadge

源码：`src/shared/ui/status-badge.jsx`

- 输出 `inline-flex items-center gap-1 rounded-full px-2 py-0.5 text-xs font-medium` + 语义浅底：`ok` → 绿色，`warn` → 琥珀，`error` → 红色，`idle` → 灰色，`primary` → indigo。
- dark 使用 `*-900/40` 浅底与 `*-200` 文字；`idle` 使用 `bg-gray-800 text-gray-300`。
- 状态必须同时有图标或文字，不只靠颜色。

## 3. 样式规则

1. 只使用 HyperUI 复制式标记与 Tailwind 工具类；不新增 `src/**/*.css` 视觉规则。
2. 颜色只使用 Tailwind 默认调色板：`gray` / `white` / `indigo` / `green` / `red` / `amber` / `blue`；不写任意色值。
3. 布局、间距、宽高、栅格与响应式使用 Tailwind 工具类；不使用自定义渐变、阴影、边框、圆角或关键帧。
4. 深色由根节点 `data-theme="dark"` + `@custom-variant dark` 控制；组件内所有表面/边框/文字都提供 `dark:` 对应类。
5. 焦点、禁用、加载、错误态使用统一类名；焦点环 `ring-2 ring-indigo-500 ring-offset-2`。
6. 新增组件前先确认 HyperUI 是否已有对应形态；能直接用类的，不再封装。
7. 颜色映射写成完整类名字符串，禁止运行时拼接 `bg-${tone}-100`。
8. Neobrutalism 只允许出现在 `src/options/sections/about.jsx`；E5 与其它页面不得出现 `shadow-[4px_4px_0_0]` / `border-2 border-black`。
