# E5 共享展示组件

| 日期 | 结论 |
| ---- | ---- |
| 20261119 | 初稿：UI 与样式统一规范化落地后建立；弹窗与设置页共用 daisyUI 展示组件 |

本文记录 E5 共享展示组件的职责、API、样式规则与可访问性约定。模块划分与依赖见 [项目架构](../项目架构.md) 4.6 与 5.1；下拉与页面交互见 [B1-状态显示](./B1-状态显示.md)、[C-设置页](./C-设置页.md)。

## 1. 职责与边界

- 为工具栏弹窗（B）与设置页（C）提供统一的 daisyUI 展示组件，保证下拉、提示、字段与状态徽标的行为、语义和视觉一致。
- 只组合 daisyUI 组件类与 Tailwind 布局类；不携带自定义 CSS，不定义颜色、圆角、阴影或动画。
- 不读写 `chrome.*`、不依赖 E1/E2/E3/E4，也不依赖 A/B/C/D。
- 不进入 content 产物；页面注入不引用 React 组件。

## 2. 组件

### 2.1 Select

源码：`src/shared/ui/select.jsx`

用途：产品内单选下拉（翻译方式、语言、日志级别、测试实例、认证方式、思考强度等）。

| 参数 | 类型 | 说明 |
| ---- | ---- | ---- |
| `id` | `string` | 容器 id（可选，默认 `useId`） |
| `value` | `string` | 当前值 |
| `options` | `Array<{ value, label, detail?, disabled? }>` | `label` 第一行，`detail` 第二行 |
| `onChange` | `(value: string) => void` | 选择回调 |
| `placeholder` | `string` | 空值/空列表文案，默认「请选择」 |
| `ariaLabel` | `string` | 触发器的可访问名称（必填） |
| `ariaDescribedBy` | `string` | 关联帮助/错误文字 |
| `disabled` | `boolean` | 禁用 |
| `loading` | `boolean` | 加载中，显示 daisyUI spinner |
| `className` | `string` | 追加布局类 |

结构：`details.dropdown` + `summary.select` + `ul.menu.dropdown-content`。触发器复用 daisyUI `select` 表单类（自带箭头与焦点环），选项使用 `menu` 项与 `menu-active` 选中态，当前项带 `Check` 图标。

状态：

| 状态 | 表现 |
| ---- | ---- |
| 展开 | 面板宽度与触发器一致，`max-h-72` 滚动；靠近视口底部时加 `dropdown-top` |
| 选择 | 更新值、关闭面板、焦点回到触发器 |
| 禁用/加载 | `aria-disabled`，阻止展开 |
| 空列表 | 面板显示占位文字 |
| 无匹配值 | 触发器显示占位文字 |

可访问性：

- `summary` 使用原生 disclosure 语义，Enter/Space 展开；`aria-haspopup`、`aria-expanded`。
- 面板为 `role="radiogroup"`，选项为 `role="radio"` + `aria-checked`，并带 `data-value` 便于定位。
- 键盘：方向键循环、Home/End、Enter/Space 选择、Esc 关闭并回到触发器、Tab 关闭。
- 点击面板外部关闭；焦点移出面板时关闭。

### 2.2 Notice

源码：`src/shared/ui/notice.jsx`

| 参数 | 说明 |
| ---- | ---- |
| `tone` | `success` / `error` / `warning` / `info` |
| `children` | 提示文字 |
| `icon` | 可选图标，默认按 `tone` 选择 lucide 图标 |
| `className` | 追加布局类 |

输出：`alert alert-{tone}`；`error` 用 `role="alert"`，其它用 `role="status"` + `aria-live="polite"`。

### 2.3 Field

源码：`src/shared/ui/field.jsx`

- 组合「标签 + 控件 + 错误 + 帮助」，错误 `role="alert"`，帮助/错误 id 分别为 `${id}-error` / `${id}-help`。
- 导出 `describedBy(id, { help, error })`，供控件生成 `aria-describedby`。
- 容器带 `data-field={id}`，供测试与定位使用。

### 2.4 StatusBadge

源码：`src/shared/ui/status-badge.jsx`

- 输出 `badge badge-sm` + 语义色：`ok` → `badge-success`，`warn` → `badge-warning`，`error` → `badge-error`，`idle` → `badge-ghost`，`primary` → `badge-primary`。
- 状态必须同时有图标或文字，不只靠颜色。

## 3. 样式规则

1. 只使用 daisyUI 主题与组件类（dark 仅由 `global.css` 覆盖 base 色阶）；不新增其它自定义 CSS。
2. 布局、间距、宽高、栅格与响应式使用 Tailwind 工具类；不使用自定义渐变、阴影、边框、圆角或关键帧。
3. 焦点、禁用、加载、错误态使用 daisyUI 默认表现。
4. 新增组件前先确认 daisyUI 是否已有对应组件；能直接使用的，不再封装。
5. 需要新增共享组件时，同步更新本文、架构 3.1/4.6/5.1 与对应测试。
