本文记录工具栏弹窗 B1 / B2 的界面细节：尺寸、信息项、交互、文案与可访问性。模块划分与流程见 [项目架构](../项目架构.md) 4.3；命令与消息见 [E1 消息协议](./E1-消息协议.md)；下拉组件见 [E5-共享展示组件](./E5-共享展示组件.md)。

## 1. 职责与边界

- 弹窗只负责「看状态」「切翻译方式」「下命令」：不持有任务、不读写页面 DOM、不调用翻译引擎。
- 读取的数据：E2 公开设置（`storage.sync` 的 `settings`）与后台 `ST_LIST_ENGINES` 返回的实例公开字段；写入的数据只有 `settings.activeInstanceId`。
- 不读取、不显示密钥明文、接口地址与 `systemPrompt`；不依赖 `src/shared/config/` 与 `src/shared/translate/`，保证弹窗产物不含引擎地址与提示词。

## 2. 界面结构与尺寸

弹窗视口宽度固定 **360px**，高度按内容自适应、上限 600px，超出时内容区内部纵向滚动。宽度写在 `src/popup/popup.css` 的 `html` / `body` / `#root` 上；其余布局与外观全部使用 Tailwind 与 daisyUI 默认主题。

| 区块 | 内容 |
| ---- | ---- |
| 标题栏 | 品牌块（`bg-primary` + Lucide `Languages`）+ `SimpleTrans`；右侧「测试页」「设置」图标链接 |
| 信息卡片 | 「翻译方式」下拉 + 目标语言 / 密钥状态徽标 + 读取失败提示 |
| 命令区 | 「翻译整页」「显示原文」并排（`grid grid-cols-2`） |
| 提示区 | 成功 / 失败 / 切换失败提示，使用共享 `Notice` |
| 页脚 | 快捷键说明「快捷键提交当前段落：`Ctrl`」，使用 `kbd` |

## 3. 翻译方式下拉

下拉使用 E5 `Select`（daisyUI `dropdown` + `menu`），触发器为 daisyUI `select` 表单类。

| 项 | 规则 |
| -- | ---- |
| 数据源 | `ST_LIST_ENGINES` 返回的实例列表 |
| 可选范围 | 只列 `enabled !== false` 且 `hasKey === true` 的实例（已启用且凭据完整；无认证 OpenAI 实例 `hasKey` 为 true） |
| 选项文案 | 第一行实例名，第二行「类型/预设 · 模型」（如 `OpenAI 兼容/deepseek · deepseek-chat`）；缺字段时退化 |
| 初始选中 | `settings.activeInstanceId`；不在可用列表时回退第一个可用实例（不写存储） |
| 无可用实例 | 下拉禁用，显示「未配置翻译方式」，并提示「没有可用的翻译实例，请到设置页新增或启用」 |
| 切换 | 立即更新显示并 `saveSettings({ activeInstanceId })`；失败则回滚选择并提示「切换翻译方式失败，请重试」 |
| 生效范围 | 只影响后续提交；进行中的翻译不中断；缓存 key 含实例的 endpoint/模型/提示词，切换后自然区分 |
| 加载态 | 读取期间显示骨架屏；切换中下拉禁用并显示 daisyUI spinner |
| 键盘 | Enter/Space 展开；方向键 / Home / End 移动；Enter 选择；Esc 关闭并回到触发器；Tab 关闭 |

## 4. 基础信息与状态标签

| 内容 | 形式 | 来源 | 缺失 / 失败 |
| ---- | ---- | ---- | ----------- |
| 目标语言 | `badge badge-sm` + 地球图标 | `settings.targetLang` 的显示名（共享语言目录） | 「未知」 |
| 密钥状态 | `badge badge-sm` + 钥匙图标：成功色「密钥已配置」、警示色「密钥未配置」、ghost「无需密钥」 | 当前实例 `hasKey` / `requiresKey` | 无实例时「密钥未配置」 |
| 读取失败 | `alert alert-error`「读取配置失败，请到设置页检查」 | 设置或实例读取失败 | — |
| 无可选实例 | `alert alert-warning`「没有可用的翻译实例，请到设置页新增或启用」 | 已启用且凭据完整的实例为空 | — |

- 「已配置」用成功色，「未配置」用警示色，不使用错误色，避免与失败提示混淆。
- 读取失败时下拉禁用、命令按钮仍可用。
- 与设置页共用同一套凭据状态口径：「已配置 / 未配置 / 无需密钥 / 部分配置」，两处文案与颜色含义一致；设置页的完整实现见 [C-设置页](./C-设置页.md)。

## 5. 图标与导航

- 图标统一来自 `lucide-react`，按名导入；装饰性图标带 `aria-hidden="true"`，不承担可访问名称。
- 使用清单：`Languages`（品牌）、`FlaskConical`（测试页）、`Settings`（设置）、`Sparkles`（翻译方式）、`Globe`（语言）、`KeyRound`（密钥）、`Play`（翻译整页）、`Eraser`（显示原文）、`Keyboard`（页脚）。
- 「测试页」与「设置」都是图标 + 文字的紧凑链接，位于标题行右侧；顺序为测试页、设置。
- 设置入口优先 `chrome.runtime.openOptionsPage()`，不可用时回退 `chrome.tabs.create({ url: chrome.runtime.getURL('options/index.html') })`；测试页经 `chrome.tabs.create` 打开 `testpage/index.html`。
- 导航打开期间各自禁用并显示「正在打开…」，失败显示一行提示，不影响命令按钮。

## 6. 视觉与可访问性

| 元素 | 样式 |
| ---- | ---- |
| 主题 | daisyUI 默认 `light` / `dark`，随 `prefers-color-scheme` 切换；不覆盖主题变量 |
| 品牌块 | `bg-primary text-primary-content rounded-box` + Lucide 图标 |
| 信息卡片 | `card bg-base-200`；不使用光斑、渐变或位移 |
| 下拉 | E5 `Select`：daisyUI `select` 触发器 + `menu` 面板 |
| 状态标签 | `badge` + 语义色 + 图标 |
| 命令按钮 | `btn btn-primary` / `btn btn-outline`；加载用 `loading loading-spinner` |
| 提示 | 共享 `Notice`（`alert`），成功/失败两态 |
| 快捷键 | `kbd kbd-sm` |
| 动效 | 只保留 daisyUI 组件默认过渡；不新增关键帧；`prefers-reduced-motion` 由组件默认与浏览器处理 |

- 所有按钮可 Tab 到达；焦点使用 daisyUI 默认焦点环。
- 状态用图标 + 文字，不只靠颜色；深色模式对比度可读。

## 7. 边界情况

| 情况 | 表现 |
| ---- | ---- |
| 后台不可用 | 卡片显示读取失败提示，下拉禁用；命令按钮点击后按后台返回的错误显示提示 |
| 没有引擎实例 | 下拉「未配置翻译方式」并禁用；密钥「密钥未配置」；提示到设置页新增或启用；导航入口可用 |
| 实例都未启用或未配置凭据 | 下拉禁用（不列不可用实例），提示到设置页处理 |
| `activeInstanceId` 指向已删除实例 | 回退第一个可用实例，不写存储、不报错 |
| 切换写入失败 | 回退原选择并提示，正在进行的翻译不受影响 |
| 弹窗内容超出一屏 | 内容区内部滚动，标题行与命令按钮不被裁切 |
| 重复点击导航按钮 | 打开期间按钮禁用，不重复打开 |
