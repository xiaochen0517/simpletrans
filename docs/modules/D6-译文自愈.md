# D6 译文自愈

| 日期 | 结论 |
| ---- | ---- |
| 20261121 | 初稿与实现（P14）：页面内存镜像、`MutationObserver` 去抖、原文未变的定稿译文自动重挂、原文变化清理旧容器；需求见 [20261121-01](../demand/20261121-01-译文重渲染自动恢复.md) |

源码：`src/content/heal.js`。页面入口 `src/content/index.js` 装配并接入生命周期；D5 在定稿帧写镜像、提供 `restore()` / `forget()`。

## 1. 职责与边界

- 页面重渲染（框架 diff、虚拟列表回收、局部刷新、宿主替换）删除译文容器后，按会话内镜像把同一译文重新挂回**原文未变**的宿主。
- 只恢复已定稿（`done`）译文；提交中、翻译中、流式、失败段落不恢复。
- 原文变化时不恢复、不重新提交：移除旧容器并让 D5 注销该段。
- 不写 storage、不发消息、不读缓存、不调用引擎、不读配置；只读页面文本与 DOM，并在内存保存镜像。
- 不直接 `console`，日志经 E4；日志只记计数与原因，不记原文、译文与完整 URL。

## 2. 数据

```js
mirror          // Map<归一化原文, { translated, at }>，上限 2000 条，按写入顺序淘汰
hidden          // Set<归一化原文>：用户主动隐藏，本次会话内不恢复
flapping        // Map<归一化原文, { count, since, pausedUntil }>：反复重建的暂停窗口
hostSources     // WeakMap<宿主, 归一化原文>：判断该宿主的原文是否变化
staleHosts      // WeakSet<宿主>：原文已变化，本次会话内不再恢复
pendingHosts    // Set<宿主>：待检查的宿主
pendingRoots    // Set<Element>：待扫描的新增子树
generation      // 递增令牌：reset 后作废排队中的检查
```

- 镜像键使用 `normalizeText(extractText(host))`，与提交给后台的段落文本同一规则；同一原文只保留最新译文。
- 镜像只在内存；`start` / `clearAll` 清空。页面 `pagehide` 只断开观察器、不清镜像，bfcache 返回后可继续使用。
- 上限与窗口见架构 5.3：去抖 150ms、候选 200、镜像 2000、抖动窗口 10 秒 / 5 次、暂停 10 秒。

## 3. 变更检测

观察 `document`（不是 `body`，以覆盖 `documentElement` 替换）：

```js
observer.observe(document, { childList: true, subtree: true });
```

- 不观察 `attributes` 与 `characterData`；只处理子节点增删。
- 观察器在首个定稿译文写入镜像后建立；页面没有任何译文时不建立观察，`reset` / `stop` 时断开。
- 回调只做筛选：命中 `[data-st-translation]` 子树的变更全部忽略（自己的写入不触发恢复）；`record.target` 向上取 `[data-st-host]` 加入宿主集合；`record.addedNodes` 中的元素加入新增子树集合。
- 新增节点若已在某个已知宿主内，只检查该宿主，不重复扫描；新增子树与已有子树互相包含时只保留最外层。
- 150ms 去抖后统一处理；同一时间只跑一轮，期间的新变更留到下一轮；`generation` 变化（清除 / 重新开始）时丢弃本轮。
- `pagehide` 断开，`pageshow` 重连；`stop()` 放弃未处理候选但保留镜像。

## 4. 恢复判定

```text
for 宿主 in 候选:
  宿主脱离文档或隐藏            → skip
  source = normalizeText(extractText(宿主))
  source 为空或没有字母         → skip
  hostSources[宿主] 存在且 ≠ source → 原文已变化：移除旧容器、注销、标记 stale → skip
  宿主已有 [data-st-translation] → skip
  source 在用户隐藏集合中       → skip
  source 在暂停窗口内           → skip
  mirror 未命中                 → skip（不恢复、不提交）
  该文本恢复次数达到阈值        → 暂停 10 秒 → skip
  D5.restore(宿主, source, 译文) 成功后记录 hostSources 与计数
```

- 新增子树交给 D1 `collectParagraphs({ root, inViewport: () => true, maxParagraphs: 200 })`，得到新宿主与文本（会补齐新的 `data-st-host`）；扫描结果再走同一判定。
- 原文变化但容器仍在时，只有容器处于 `done` 才移除；提交中/翻译中不打断，交给结果帧收尾。
- `D5.restore()` 只做四件事：确保段落 id、显示 `done`、写注册表、加入 `attemptedHosts`；不写 `submittedHosts`、不提交。

## 5. 接口

```js
const healer = createHealer({
  document,
  renderer,                     // D3，用于移除原文已变化的旧容器
  restore: (host, source, translated) => task.restore(host, source, translated),
  forget: (host) => task.forget(host),
  // 其余依赖用于测试注入：scan / extract / normalize / hasLetter / isHidden
  // / logger / now / schedule / cancel / MutationObserverCtor / yieldToMain
});

healer.start();                 // 镜像非空时建立观察；没有 document 或 MutationObserver 时返回 false
healer.stop();                  // 停止观察并放弃未处理候选，保留镜像
healer.reset();                 // 清空镜像、隐藏集合、抖动计数与宿主映射
healer.remember(source, translated, host); // D5 定稿时写入；空串不写入
healer.hide(source);            // 用户隐藏：本次会话不恢复该文本
healer.unhide(host, source);    // 重新提交：解除隐藏与该宿主的过期标记
healer.getMirrorSize();         // 测试与诊断
```

D5 侧对应接口：

```js
task.restore(host, source, translated); // 挂回 done 译文，写 registry / attemptedHosts，不加 submittedHosts
task.forget(host);                      // 删除 registry 与 latestRequest，页面显示由 D6 移除
```

## 6. 与页面任务、生命周期的衔接

| 时机 | 行为 |
| ---- | ---- |
| `ST_ITEM_DONE` | D5 写 `done` 后调用 `remember(source, translated, host)` |
| 悬停隐藏 | D5 移除标记后调用 `hide(source)` |
| 悬停重新提交 / 失败段刷新 | D5 调用 `unhide(host, source)`，允许后续恢复 |
| 重新开始翻译 / 显示原文 | D5 先调用 `reset()`，再 `renderer.clearAll()`；排队中的恢复作废 |
| 页面卸载 | 页面入口 `stop()`；镜像保留到文档销毁 |
| bfcache 返回 | 页面入口 `start()`；镜像仍在，可继续恢复 |
| 连接断开 / 恢复 | 不影响 D6；恢复不依赖后台 |

| `heal.stale` | debug | 移除旧容器的数量（`removed: 0/1`） |

## 8. 边界与已知限制

- 原文变化但只改字符数据（`characterData`）、容器未删时观察不到；旧译文可能过期，需用户重新触发。
- 原文变化且容器被删时，按 `hostSources` 判定并清理；宿主被整体替换时没有旧映射，只能按文本命中，因此「新文本恰好曾被翻译过」的段落会按同文同译恢复。
- 同一原文的多个宿主共享同一译文；镜像按文本匹配，不区分段落位置。
- 页面刷新（F5）、扩展重载、标签页重开不恢复（镜像在页面内存）。
- 翻译中 / 流式 / 失败段落不恢复；容器若被删保持现状。
- 每秒重写 DOM 的站点：同一文本达到阈值后暂停 10 秒，避免与页面互相触发。
- Shadow DOM、Canvas、跨源不可注入内容不在范围。
- 宿主被隐藏（`hidden` / `aria-hidden` / `display:none` / 闭合 `details`）时不恢复，等可见后再由下一次变更触发。

## 9. 测试

`tests/unit/heal.test.js`（jsdom）：

- 镜像写入、覆盖、空值、2000 条上限；
- 子节点重建删除容器后重挂；宿主替换后按文本重挂；自身写入不触发第二次恢复；
- 原文变化不移除容器与移除容器两条路径；新文本在镜像里也不恢复该宿主；
- 容器仍在时不重复恢复；用户隐藏与解除；清除后不恢复；隐藏宿主不恢复；
- 达到阈值后暂停；`stop` / `start` 生命周期；连续重建只检查一轮。
