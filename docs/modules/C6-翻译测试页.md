## 1. 职责与边界

- 提供固定、离线可用的英文正文，覆盖标题、段落、列表、表格、引用、代码、表单、长文与负例，供人工验证整页提交、滚动增量、Ctrl 单段提交、结果回显与显示原文；译文来自后台缓存命中或真实翻译。
- 顶部操作条只提供「翻译整页」「显示原文」两个按钮与状态文字；操作条标记 `translate="no"` 与 `data-simpletrans-ignore`，不参与翻译。
- 页面静态导入 D 入口 `src/content/index.js`，在扩展页内启动同一套 D1–D5 运行时；通过 D 入口导出的 `getTask()` 取得当前 D5 任务，直接调用 `start({})` / `clearAll()`。
- 不生成正文、不读写配置、不直接调用引擎、不发送 `ST_ROUTE`、不写 `storage`。
- 不经过清单 `content_scripts` 注入，也不改变普通网页的注入与弹窗命令路径；C6 是唯一允许依赖 D 入口的独立页面。

## 2. 页面结构

所有区块按固定顺序出现，带稳定 `id` 与 `data-test-section`；页脚在 `main` 之后，同样带 `data-test-section`。

| 区块 id | 内容 | 用途 |
| ------- | ---- | ---- |
| `overview` | 标题、短段落、元信息 | 基础段落与页面顶部观察 |
| `typography` | `strong` / `em` / `small` / `mark` / `abbr` / `code` / `a` / `sup` / `sub` | 行内标签与嵌套行内结构 |
| `lists` | `ul` / `ol` / 嵌套列表 / `dl` | 列表项与定义列表 |
| `tables` | `caption` / `thead` / `th` / `td` / 金额 | 表格单元格与表头 |
| `quotes-code` | `blockquote` / `cite` / `pre` / `code` / `<br>` | 引用、代码块与显式换行 |
| `controls` | 卡片、徽标、按钮、`label`、输入、`textarea`、`select`、复选框、单选、范围、禁用控件 | 可翻译标签与应跳过的控件状态 |
| `numbers` | 日期、时间、货币、百分比、度量、电话、邮箱、URL、引号、破折号、省略号 | 数字与标点保持 |
| `long-article` | 10 个自然段与 5 个 `h3` 小节 | 滚动与视口取段 |
| `non-translatable` | `translate="no"`、`.notranslate`、`[data-simpletrans-ignore]`、`contenteditable`、输入值、占位符、`select` 选项、`hidden`、闭合 `details`、`aria-hidden` | 不翻译的负例 |
| `footer` | 页脚短句、内部锚点、版本行 | 页脚与内部链接 |

页面正文全部为英文；操作条为中文。正文不包含外部脚本、样式、字体、图片或媒体资源；内部链接只使用 `#` 锚点。

## 3. 加载与操作

### 3.1 运行时加载

`src/testpage/main.js` 静态导入 `../content/index.js`。导入时 D 入口顶层 `main()` 执行：

1. 初始化 E4 日志；
2. 创建并连接 `st-gateway` 桥；
3. 装配 D1 扫描、D3 渲染、D5 页面任务与 D2 悬停；
4. 安装 Ctrl 单键手势；
5. 注册 `ST_TOGGLE` / `ST_CLEAR` / `ST_START` 消息监听。

测试页随后通过 `getTask()` 取得同一个 D5 任务。页内按钮与 Ctrl 手势共用这一份任务状态。

这条路径不经过 `content.js` 的 IIFE 打包与清单注入，因此验证的是取段、渲染、任务、缓存与网关逻辑本身；真实网页注入路径不受影响。

### 3.2 操作条

| 元素 | 行为 |
| ---- | ---- |
| `#test-start`「翻译整页」 | 调用 `getTask().start({})`；按钮进入忙碌态并禁用，状态显示「正在扫描页面…」或「正在提交页面段落…」；提交结束后显示「已提交 N 段，滚动后自动提交新段落」或「视口附近没有可翻译的段落」；失败显示 D5/后台返回的消息。提交成功后滚动页面，新进入视口附近的段落自动补交并回显 |
| `#test-clear`「显示原文」 | 调用 `getTask().clearAll()`；状态显示「已清除 N 处标记」；失败显示错误 |
| `#test-status` | `role="status"`；`data-tone="error"` 时用错误色 |
| 操作提示 | 说明 Ctrl 提交/隐藏、滚动自动提交，以及译文来自后台缓存或真实翻译 |

整页任务做视口附近取段、统一提交、滚动增量、按段落 id 回显与「已提交 / 翻译中 / 流式 / 译文 / 失败」显示；结果来自后台 D4 帧（缓存命中或真实翻译）。页面加载时不自动翻译，也不自动滚动；只建立与后台的连接。D 运行时没有就绪时，按钮禁用并显示「页面注入未就绪，请刷新页面」。

### 3.3 表单

测试页的演示表单只用于展示控件文字，`main.js` 阻止表单默认提交，避免按 Enter 离开夹具。输入值、占位符、`select` 选项与禁用控件是负例，不应被翻译；`label`、说明文字与按钮文字是普通文本，可以翻译。

## 4. 错误与提示

| 场景 | 表现 |
| ---- | ---- |
| D 运行时未就绪 | 状态「页面注入未就绪，请刷新页面」；两个按钮禁用 |
| 启动翻译失败 | 状态显示 `result.error.message` 或「启动翻译失败」 |
| 清除失败 | 状态显示「清除失败：…」 |
| 后台未配置密钥 / 鉴权失败 | 每段显示「翻译失败：<后台 message>」（如「缺少密钥，请先在设置页保存密钥」）；状态区仍显示已提交段数 |
| 翻译失败 | 该段显示「翻译失败：<错误 message>」；重新触发可重试 |
| 单段超过 4000 字符 | 该段显示「翻译失败：单段超过 4000 字符」；其它段落继续翻译 |
| 扩展重载导致上下文失效 | D4 输出「扩展已重新加载，请刷新页面」；刷新测试页后恢复 |
| 在测试页点击弹窗「翻译整页」 | 后台补注入扩展页失败，弹窗显示「当前页面无法翻译，请在普通网页上使用」；测试页操作条仍可用 |

测试页不捕获并吞掉错误；所有错误都落到状态区或现有日志。

## 5. 边界与已知限制

- 测试页是扩展页面，不能接收清单注入或 `chrome.tabs.sendMessage`；弹窗翻译按钮不驱动它，页内操作条是推荐入口。
- 测试页与普通网页共用后台缓存、分组切批与真实翻译；需要验证请求差异时，在设置页清空缓存。
- 页面不监听 `MutationObserver`，也不自动追加内容；固定夹具本身不变化，滚动增量只由用户滚动触发。
- 测试页不验证真实 content script 注入，也不验证 `content.js` 的 IIFE 产物；这些由普通网页人工验收覆盖。
- 页面只提供浅色样式，不提供主题切换；480px 以下表格在自身容器内横向滚动。
- 操作条中文与正文英文是固定约定，不随扩展语言设置变化。
