| 日期 | 结论 |

源码：`src/content/dom/renderer.js`、`src/content/content.css`。

## 1. 职责与边界

- 把译文以行内容器内嵌到被翻译节点末尾，支持加载、流式、完成、失败四种显示状态。
- 支持单段隐藏与清除全部；隐藏只移除译文容器，原文与宿主标记不动。
- 不提取文本、不判断段落、不发请求、不读 storage；这些分别属于 D1、D2、D5。
- 不直接写日志；状态变化由 D5 记录，避免每个增量产生日志。

## 2. DOM 契约

译文容器固定为 `<font>`，作为宿主最后一个子节点；容器内再放一个 `<font>` 承载译文文本。宿主可以是任意标签（`p`、`span`、`button`、`a`、`code` 等）：

```html
<!-- 段落：宿主计算样式为块级 -->
<p data-st-host="h1">Original <strong>text</strong>.
  <font data-st-translation=""
        data-st-for="h1"
        data-st-state="done"
        data-st-mode="block"
        dir="auto"><br><font>译文</font></font>
</p>

<!-- 行内 / inline-block 宿主 -->
<span data-st-host="h2">原文<font data-st-translation=""
      data-st-for="h2"
      data-st-state="done"
      data-st-mode="inline"
      dir="auto">&nbsp;&nbsp;<font>译文</font></font></span>

<!-- 按钮宿主 -->
<button data-st-host="h3">Submit<font data-st-translation=""
        data-st-for="h3"
        data-st-state="done"
        data-st-mode="inline"
        dir="auto">&nbsp;&nbsp;<font>提交</font></font></button>
```

| 标记 | 位置 | 含义 |
| ---- | ---- | ---- |
| `data-st-host` | 原文节点 | D1 分配的宿主 id（`h1`、`h2`…） |
| `data-st-translation` | 外层译文容器 | 存在即表示该宿主有加载、流式、完成或失败显示 |
| `data-st-for` | 外层译文容器 | 指向宿主 id，供悬停与清理使用 |
| `data-st-state` | 外层译文容器 | `loading` / `streaming` / `done` / `error` |
| `data-st-mode` | 外层译文容器 | `block`（宿主块级，`<br>` 换行）/ `inline`（宿主行内，`&nbsp;&nbsp;` 分隔） |
| `dir` | 外层译文容器 | 固定 `auto`，兼容 RTL 目标语言 |

> 行内示例用 `<span>` 与 `<button>` 说明格式；P4 的 D1 会把指针最近的文字标签作为宿主，因此行内标签的译文会留在该标签内部。

- 译文只写入内层 `<font>` 的 `textContent`，禁止 `innerHTML`；`<br>` 与分隔空格是固定结构，不来自页面或模型输出。
- 同一宿主重复显示时复用同一个容器，不叠加第二个。
- 容器被页面脚本删除后，下一次更新重建；宿主已从文档移除时删除容器并清掉状态。

## 3. 插入位置与格式

1. 永远 `host.appendChild(container)`：译文是宿主最后一个子节点。
2. 模式由宿主计算样式决定，不按标签名判断：
   - `block` / `flow-root` / `list-item` / `table` / `table-cell` / `table-caption` / `flex` / `grid` 等块级容器 → `data-st-mode="block"`：容器内先放 `<br>`，再放内层 `<font>`；译文另起一行，不增加外边距。
   - `inline` / `inline-block` / `inline-flex` / `inline-grid` / `inline-table` / `ruby` 等行内级 → `data-st-mode="inline"`：容器内先放两个 U+00A0，再放内层 `<font>`；译文与原文同一行，以两个空格分隔。
   - `display: contents` 时向上找到实际参与布局的祖先，再用该祖先的 `display` 判断。
3. 容器保持 `display: inline`，`data-st-mode` 只记录宿主布局，不代表容器自身 `display`。
4. 不增加 `margin` / `padding` / `border`；段落间距、列表标记、表格边框、缩进与悬挂缩进保持原样。

已知限制：

- 宿主是 flex / grid 时，容器会成为 flex / grid 项目，`<br>` 只在项目内部换行，可能无法与原文上下排列；P4 不引入站点规则，由人工验收覆盖。
- 页面用 `!important` 强制 `font` 样式时，`all: unset` 也可能被覆盖。
- 标题宿主的译文继承标题字号，这是「样式随宿主」的预期结果。
- 内嵌后宿主 `textContent` / `innerText` 包含译文；D1 提取已排除，页面脚本读取与选中复制会看到译文（复制行为已确认接受）。

## 4. 状态与样式

| 状态 | 容器内容（内层 `<font>` 为译文文本） | 样式 |
| ---- | ------------------------------------ | ---- |
| `loading` | 块级宿主：`<br><font>正在翻译…</font>`；行内宿主：`&nbsp;&nbsp;<font>正在翻译…</font>` | 不透明度 0.55 |
| `streaming` | 内层 `<font>` 为累计增量文本 | 不透明度 0.55 |
| `done` | 内层 `<font>` 为定稿译文 | 不透明度 0.92 |
| `error` | 内层 `<font>` 为 `翻译失败：<提示>` | 不透明度 0.8、斜体、点线下划线 |

```css
[data-st-translation] {
  all: unset;
  display: inline;
  font: inherit;
  line-height: inherit;
  color: inherit;
  text-align: inherit;
  white-space: inherit;
  overflow-wrap: anywhere;
  opacity: 0.92;
  cursor: text;
}

[data-st-translation] > font {
  all: unset;
  font: inherit;
  color: inherit;
  white-space: inherit;
}
```

- 只用 `data-st-*` 选择器，不命中页面原有元素。
- 颜色、字体、字号、字重、行高、字距、对齐与 `white-space` 全部继承宿主，不硬编码颜色，深色页面可读。
- 错误态不依赖颜色区分；加载/流式只降低不透明度。

## 5. 接口

```js
const renderer = createRenderer({ document });
renderer.showLoading(host);        // 插入/复用容器，写入加载提示
renderer.update(host, text);       // 流式更新（D5 已合并增量）
renderer.showDone(host, text);     // 定稿
renderer.showError(host, message); // 失败
renderer.remove(host);             // 隐藏单段，移除整个容器（含 br / 分隔空格）
renderer.clearAll();               // 清除全部，返回移除数量
renderer.getState(host);           // loading | streaming | done | error | null
renderer.getText(host);            // 读内层 <font> 的译文文本
renderer.has(host);
```

- 渲染方法要求宿主已有 `data-st-host`；`data-st-for` 直接读该属性。
- `showError` 对空消息回退为「翻译失败，请重试」。
- 状态切换只改容器属性与内层 `<font>` 的文本，`<br>` / 分隔空格位置不变。

## 6. 错误与提示

| 情况 | 页面显示 |
| ---- | -------- |
| 请求中 | 正在翻译… |
| 定稿为空 | 翻译失败：引擎返回空译文，请重试 |
| 段失败 / 整批拒绝 | 翻译失败：<后台 message> |
| 连接断开 | 翻译失败：与后台的连接已断开，请稍后重试 |
| 补注入后连接超时 | 翻译失败：连接后台超时，请稍后重试 |
| 段落超长 | 翻译失败：段落超过 4000 字符，暂不支持 |
| 错误后再次触发 | 清除错误并重新请求 |

## 7. 边界情况

- 宿主在文档外：`show*` 返回 `false`，不抛错；已有容器会被移除。
- 容器被页面删除：下一次 `show*/update` 重建。
- 同一宿主在流式期间被隐藏：D5 取消请求并调用 `remove`，后续帧被忽略。
- 页面刷新：译文不持久化，全部消失。
- 宿主文本包含译文：D1 的 `extractText` 排除 `[data-st-translation]` 子树，D5 不直接读 `textContent`。
