本文记录弹窗「快速翻译」页的界面细节：输入、选区读取、临时实例与目标语言、结果展示、提示词行为与错误提示。模块划分见 [项目架构](../项目架构.md) 4.3；消息见 [E1-消息协议](./E1-消息协议.md)；弹窗壳与默认页见 [B1-状态显示](./B1-状态显示.md)；提示词编辑见 [C-设置页](./C-设置页.md)。

## 1. 职责与边界

- 只负责弹窗内的输入、选择、请求与展示：不写页面 DOM、不注入页面脚本、不使用译文缓存、不写 `storage`。
- 读取的数据：`ST_LIST_ENGINES` 的实例公开字段、`GET_SELECTION` 的选区文本、`ST_QUICK_TRANSLATE` 的译文；组件状态只在自己的内存里。
- 实例、目标语言、输入与结果都是弹窗会话状态：关闭弹窗即消失，不改变 `settings.activeInstanceId` 与 `settings.targetLang`。
- 不读取、不显示提示词正文；提示词只在设置页实例编辑弹窗中编辑。

## 2. 界面结构

快速页位于弹窗标签栏的「快速翻译」下，与默认页共用 360px 宽、最高 600px 的弹窗；两个面板都保持挂载，切换标签只切换可见性（`hidden`），因此输入、结果与本页提示不会因切换而丢失。

| 区块 | 内容 |
| ---- | ---- |
| 设置卡片 | 「翻译实例」下拉、「目标语言」下拉；不显示说明文字或实例类别提示 |
| 输入卡片 | 多行 `textarea`、`N / 4000` 计数、「读取选区」与「翻译」按钮、`Ctrl + Enter` 快捷键说明 |
| 结果卡片 | 「译文」标题、实例名 · 目标语言徽标、「复制」按钮、`pre-wrap` 纯文本 |
| 提示 | 选区截断 / 已复制等成功提示，后台错误提示 |

- 实例下拉只列 `enabled !== false` 且 `hasKey === true` 的实例；选项两行：实例名 / 「类型·预设·模型」。
- 目标语言下拉列出共享语言目录的全部目标语言，初始为全局目标语言。
- 没有可用实例时下拉禁用，显示「没有可用的翻译实例，请到设置页新增或启用」，翻译按钮禁用；读取配置失败时显示「读取配置失败，请到设置页检查」。

## 3. 输入与选区

| 情况 | 行为 |
| ---- | ---- |
| 首次进入快速页 | 发一次 `ST_GET_SELECTION`；输入为空才填入选区，已有输入不覆盖 |
| 切走再切回 | 不重复读取选区，输入与结果保持 |
| 「读取选区」 | 总是重新读取；有选中文字则覆盖输入并提示「已填入页面选中文字」，没有则提示「未读取到选中文字」 |
| 选区超长 | 后台截断到 4000 字符并返回 `truncated`，页面提示「选区超过 4000 字符，已截取前 4000 字符」 |
| 页面不可注入 | 后台返回空文本，页面不报错，仍可手动输入 |
| 手动输入 | `textarea` 上限 4000 字符（`maxLength`），显示计数；空输入时翻译按钮禁用 |
| 快捷键 | `Ctrl+Enter`（macOS 也接受 `Meta+Enter`）触发翻译；单独 `Enter` 只换行 |
| 请求中 | 输入、下拉与按钮禁用；重复点击或快捷键被忽略 |

## 4. 临时实例与目标语言

- 初始实例：`settings.activeInstanceId` 在可用列表中则用它，否则用第一个可用实例；不写存储。
- 切换实例或目标语言只改本页状态；不写 `settings.activeInstanceId`、不写 `settings.targetLang`，也不新增独立的快速实例设置。
- 请求载荷携带当次的 `instanceId` 与 `targetLang`，后台按这两个值解析实例与语言。
- 关闭弹窗后临时选择失效；下次打开恢复为当前实例与全局目标语言。

## 5. 结果与复制

- 结果区使用 `whitespace-pre-wrap break-words` 的纯文本，保留模型输出的换行；不解析 Markdown、不写 HTML。
- 元信息显示「实例名 · 目标语言」；目标语言取后台返回的 `targetLang`，避免翻译后切换语言造成文案不一致。
- 「复制」使用 `navigator.clipboard.writeText`，成功提示「已复制」；不可用时提示「复制失败，请手动选择文本复制」。
- 失败时保留输入与选择，允许直接重试；成功结果只保留最后一次，不写存储。

## 6. 提示词行为

- OpenAI 兼容实例：使用实例的快速翻译提示词（`quickPrompt`，缺失回退默认模板）；A5 以 `mode='quick'` 调用 A3，`{{outputFormat}}` 展开为词典式快速格式：
  - 单词/短语：第一行 `/音标/`；随后每个词性一行释义，行尾「；」，同一词性的多个义项用「；」分隔；最后最多两条例句，原文与译文同一行；
  - 句子/段落：只输出目标语言译文。
- 单词结果示例（目标语言中文，输入 `hello`）：

  ```text
  /həˈloʊ/
  int. 喂，你好（用于问候或打招呼）；
  n. 招呼，问候；
  v. 说（或大声说）“喂”；
  Hello, how are you? 你好，你好吗？
  She said hello to me. 她向我打了招呼。
  ```

- 百度翻译实例：不使用提示词，直接返回目标语言译文。
- 页面不判断单词还是句子，也不在本地拼装音标/词性；输出完全来自模型，页面只按纯文本逐行展示。
- 快速翻译不读写 A4 缓存，重复翻译同一内容会再次请求上游。

## 7. 错误与提示

| 错误码 | 典型提示 | 处理 |
| ------ | -------- | ---- |
| `CONFIG` | 扩展已停用 / 没有可用的翻译实例 / 该实例已停用，请重新选择 / 缺少密钥 / APPID 或密钥未配置完整 / 未授权访问该接口域名 | 修正配置或换实例；输入保留 |
| `OTHER` | 请输入待翻译文本 / 文本超过 4000 字符上限 / 不支持的目标语言 | 修正输入或语言 |
| `AUTH` / `RATE_LIMIT` / `NETWORK` / `BATCH_ALIGN` | 后台映射后的用户提示 | 稍后重试或检查实例配置 |
| 选区读取失败 | 无提示（静默空文本） | 手动输入或点「读取选区」重试 |

后台错误不透传上游原始报文；弹窗只显示错误文案。

## 8. 可访问性与主题

- 两个标签使用 `tablist` / `tab` / `tabpanel` 语义与 `aria-selected`；快速页根节点在非激活时带 `hidden`，读屏与 Tab 不会进入隐藏面板。
- 输入、下拉、按钮都可 Tab 到达；下拉沿用 E5 `Select` 的键盘与 ARIA。
- 结果区 `aria-live="polite"`，翻译完成后可被读屏读出。
- 使用 HyperUI/Tailwind 类与共享 `Notice`，深色由根节点 `data-theme="dark"` + `dark:` 变体控制；实际主题由 `settings.theme` 决定；不新增其它自定义视觉 CSS。

## 9. 边界情况

| 情况 | 表现 |
| ---- | ---- |
| 弹窗打开时全局配置读取失败 | 快速页显示读取失败提示，实例列表为空，翻译禁用 |
| 选中的实例在别处被删除或停用 | 本页选择保持到下次请求，后台返回「实例不存在 / 已停用」，提示重新选择 |
| 关闭弹窗时请求未完成 | 后台请求可能继续完成，但结果直接丢弃，不写存储 |
| 选区为空或页面不可注入 | 输入保持为空，不阻塞手动输入 |
| 结果很长 | 结果卡片随弹窗内容区滚动，文本自动换行，不横向溢出 |
| 重复快速翻译 | 请求中禁用按钮与快捷键；结果整体替换 |
| 目标语言在结果之后被切换 | 结果元信息仍显示本次翻译使用的语言 |
