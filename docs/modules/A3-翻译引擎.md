## 1. 职责与边界

- **唯一出口**：所有翻译（整页、悬停、设置页测试）都经 A3 适配器调用引擎，其它模块不得各自发请求。
- P2 只做**单段翻译**，具备流式输出与取消能力；批量编码与按段对齐归 `batch.js`（P6）。
- 密钥与接口地址来自实例（由 E3 解析），A3 不直接读写存储；密钥不进日志、不进产物。

## 2. 接口与数据结构

适配器契约（`src/shared/translate/adapter.js`）：

```js
translate({ text, targetLang, instance, onDelta, signal }) → { text, usage }
mapError(error) → { code, message }
isSupportedTargetLang(lang) → boolean
buildSystemPrompt({ targetLang, template, mode }) → string
hashPrompt(template) → Promise<string>
isDefaultPrompt(template) → boolean
deepseekProviderOptions(instance) → ProviderOptions
PROMPT_VERSION // 提示词模板与输出格式的结构版本，当前 2
```

- `text`：待译原文（字符串）。
- `targetLang`：目标语言代码（当前仅 `zh`，映射为「中文」）；`SUPPORTED_TARGET_LANGS` 是唯一语言表。
- `instance`：已解析的引擎实例，字段含 `apiKey`、`baseUrl`、`model`、`systemPrompt`、`reasoningEffort`（由 E3 提供）。
- `onDelta(增量文本)`：可选回调，流式期间逐段转发增量。
- `signal`：可选 `AbortSignal`；外部取消时中断上游。P2 起支持，向后兼容。
- 返回 `usage`：`{ promptTokens, completionTokens, totalTokens }`（缺省为 `null`）。

失败时抛 `TranslateError`（含 `code` 统一错误码与 `message` 用户提示）。

DeepSeek 实现要点：

- 用 `createDeepSeek({ apiKey, baseURL })` 构造 provider，`provider.chat(model)` 取模型；
- 用 `streamText({ model, system, prompt, abortSignal, providerOptions })` 流式生成，`textStream` 聚合增量；
- 外部 `signal` 与 `AbortSignal.timeout(AI_TIMEOUT_MS.total)` 用 `AbortSignal.any` 合并（Chrome 116+，与清单最低版本一致）；
- 调用前与异常时都检查外部 `signal.aborted`，优先映射 `CANCELLED`；只有超时才映射 `NETWORK`。
- `streamText` 的 `usage` 是延迟 Promise：流中断时它会 reject。取消/异常的 `catch` 中调用 `observePendingUsage(result)`，给该 Promise 挂一个 `catch`，避免未处理拒绝；不读取值，成功路径仍正常 `await result.usage`。

## 3. 提示词模板与输出归一

- 提示词是实例上的完整模板（`instance.systemPrompt`，E3 默认值 + 设置页可编辑），本模块只负责展开与兜底。
- 两个程序占位符：
  - `{{targetLang}}`：替换为目标语言显示名（当前只有 `zh` → 「中文」；未知语言回退语言码）。
  - `{{outputFormat}}`：按调用模式替换为程序提供的输出规则。单段（`mode='single'`）要求只输出译文本身；批量（`mode='batch'`）为 P6.4 的 JSONL 规则（每行一个 `{"id":"...","text":"..."}`，id 必须与输入一致，不输出解释或代码块）。
- 替换时替换全部同名占位符；空模板或缺少模板时回退默认模板（`DEFAULT_SYSTEM_PROMPT`，定义在 E3 的 `registry.js`）。
- 保存校验只保证两个占位符存在、长度与非未知占位符；不限制用户增删防注入语句或风格要求。默认模板包含防注入与逐段独立翻译要求，删除后由用户自行负责。
- `hashPrompt(template)`：模板去首尾空白、统一换行后做 SHA-256（小写十六进制）；换行差异不影响哈希。A2 每个批次计算一次并放进缓存 key，计算失败时本批不参与缓存。
- 输出归一（`normalizeOutput()`）：去首尾空白，剥一层成对引号/书名号等包装，只保留译文。
- `PROMPT_VERSION=2`：提示词模板化、占位符与单段/批量输出格式属于新的结构版本；提示词结构、默认模板或语言显示名映射再变化时递增。A4 缓存 key 纳入该值，旧条目随之失效。
- `BATCH_ENCODING_VERSION=1` 在 `batch.js` 中定义并预留，P6.4 使用；P6.2 的缓存 key 已包含该字段。

## 4. 思考参数

- 按实例 `reasoningEffort` 构造 DeepSeek `providerOptions`：

```js
{
  deepseek: {
    thinking: { type: effort === 'off' ? 'disabled' : 'enabled' },
    ...(effort === 'off' ? {} : { reasoningEffort: effort }),
  },
}
```

- `off` 关闭思考且不传 `reasoningEffort`；`low` / `medium` / `high` / `max` 开启思考并传对应强度（`medium` 由 SDK 映射为 `high`）。
- 非法值在 E3 归一为 `off`，不会传给上游。
- 思考模式不设置 `temperature`、`presence_penalty`、`frequency_penalty`（这些参数在思考模式下无效）。
- 页面翻译与设置页测试翻译使用同一适配器函数，不存在两套提示词或参数。

## 5. 错误与提示

上游错误经 `mapError()` 映射为统一错误码，不把原始报错透传给页面：

| 条件 | 错误码 | 提示 |
| ---- | ------ | ---- |
| 缺密钥（调用前短路） | `CONFIG` | 缺少密钥，请先在设置页保存密钥 |
| 外部取消 / 已取消的 signal | `CANCELLED` | 翻译已取消 |
| HTTP 401 / 鉴权类文案 | `AUTH` | 密钥无效或鉴权失败 |
| HTTP 402 / 额度类文案 | `AUTH` | 额度不足或账户欠费 |
| HTTP 429 / 限流类文案 | `RATE_LIMIT` | 请求过于频繁，请稍后重试 |
| 网络错误名 / 网络超时关键词 | `NETWORK` | 网络错误或请求超时 |
| 其它 | `OTHER` | 翻译失败：<原始信息> |

错误码与 `retryable`/`splittable`/`fallbackable` 标志见 [E1-消息协议](./E1-消息协议.md)。

## 6. 日志

- 使用 E4（`src/shared/log/`），不直接调用 `console.*`。
- 记录事件：`engine.request`、`engine.done`、`engine.cancel`、`engine.error`。
- `engine.request` / `engine.done` 数据含引擎类型、模型名、`reasoningEffort`、`promptVersion`、`promptDefault`（是否默认模板）、耗时、用量与错误码；取消记为 `engine.cancel`（info），不作为错误。
- 不记录提示词正文与哈希、页面原文、译文、密钥、请求头/体、完整地址；上游原始错误只保留统一错误码与安全提示。
- 日志失败不影响翻译；不因日志改变错误映射、取消或超时行为。

## 7. 边界情况

- **空文本**：返回 `{ text: '', usage: null }`，不发上游请求。
- **缺密钥**：抛 `TranslateError(CONFIG)`，不触发上游调用。
- **已取消**：调用前 `signal.aborted` 为真时直接抛 `CANCELLED`，不调用上游。
- **缺提示词**：实例没有 `systemPrompt` 或为空时回退默认模板；占位符仍由 `buildSystemPrompt` 展开。
- **非法思考强度**：E3 归一为 `off`；适配器再次归一，不把未知值传给上游。
- **流式聚合**：`textStream` 全量消费后读 `usage`；`onDelta` 只在有增量时调用。
- **超时**：`AbortSignal.timeout` 触发中止 → 映射为 `NETWORK`。
- **外部取消**：用户取消触发 abort → 观察并处理 `usage` 的拒绝 → 映射为 `CANCELLED`，网关据此回 `ST_ITEM_ERROR(CANCELLED)`；日志为 `engine.cancel`。
- **上游异常**：任何非 `TranslateError` 异常都经 `mapError` 归一后重抛为 `TranslateError`。
