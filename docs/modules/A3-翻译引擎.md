## 1. 职责与边界

- **唯一出口**：所有翻译（整页、悬停、设置页测试）都经 A3 适配器调用引擎，其它模块不得各自发请求。
- **单段与批量**：单段走 `translate`（流式）；同一批次的多个段落走 `translateBatch`（JSONL，一次请求，按段回调）。
- **队列**：批次由 A3 的全局 FIFO 队列执行，按实例 `maxConcurrency` 限制同时在途的 job 数；队列不持久化、不写缓存、不持有页面连接。
- 密钥与接口地址来自实例（由 E3 解析），A3 不直接读写存储；密钥不进日志、不进产物。
- 空文本、缺密钥、已取消都在调用上游前短路；批量对齐失败按 `BATCH_ALIGN` 上抛，已解析段落保留。

## 2. 接口与数据结构

### 2.1 单段翻译

```js
translate({ text, targetLang, instance, onDelta, signal }) → { text, usage }
```

- `text`：待译原文（字符串）；空文本返回 `{ text: '', usage: null }`，不发请求。
- `targetLang`：目标语言代码（当前仅 `zh`，映射为「中文」）；`SUPPORTED_TARGET_LANGS` 是唯一语言表。
- `instance`：已解析的引擎实例，字段含 `apiKey`、`baseUrl`、`model`、`systemPrompt`、`reasoningEffort`（由 E3 提供）。
- `onDelta(增量文本)`：可选回调，流式期间逐段转发增量。
- `signal`：可选 `AbortSignal`；外部取消时中断上游。
- 返回 `usage`：`{ promptTokens, completionTokens, totalTokens }`（缺省为 `null`）。
- 失败时抛 `TranslateError`（含 `code` 统一错误码与 `message` 用户提示）。

### 2.2 批量翻译

```js
translateBatch({ items, targetLang, instance, onItem, signal }) → { usage }
```

- `items`：`[{ groupId, text }]`，`groupId` 在 job 内唯一（队列生成 `g0`、`g1`…）。
- `onItem({ groupId, text })`：每解析出一段就调用一次；译文已过 `normalizeOutput()`。
- 空 `items` 返回 `{ usage: null }`，不发请求。
- 一次 `streamText`：system 用批量 `{{outputFormat}}`，prompt 为 JSONL 输入；输出逐行解析。
- `signal` 与 `AbortSignal.timeout(AI_TIMEOUT_MS.batchTotal)` 用 `AbortSignal.any` 合并；超时从开始执行时计时，不含排队。
- 批量 `usage` 只返回给队列/A2；多段批每个 `ST_ITEM_DONE.usage` 为 `null`。
- 对齐失败抛 `BatchAlignError`（`code = 'BATCH_ALIGN'`，`counts` 只含计数）。

### 2.3 批量编码与解析

```js
encodeBatchInput(items) → string
createBatchParser(expectedIds, { onItem }) → { push(chunk), end() → Map<id, text> }
parseBatchOutput(text, expectedIds) → Map<id, text>
BatchAlignError
BATCH_ENCODING_VERSION // 当前 1
```

- 输入：每行一个 `{"id":"g0","text":"..."}`，行间 `\n`；`JSON.stringify` 保证引号、反斜杠与换行安全；不发送上下文、页面信息或提示词。
- 输出：每行一个 `{"id":"...","text":"译文"}`，顺序不限；只按 id 对齐，不按位置猜。
- 只在完整行上解析；末尾无换行的最后一行在 `end()` 时解析；忽略空行与单独的代码围栏行（```` ``` ```` / ```` ```json ````）。
- 校验 id 为字符串、在期望集合内、未重复，`text` 为字符串；缺失、重复、未知、非 JSON 或非字符串 `text` 都抛 `BatchAlignError`。
- 已解析段落保留；失败发生在后续行时，调用方只把未完成段落标 `BATCH_ALIGN`。
- `BATCH_ENCODING_VERSION` 在行格式或解析规则变化时递增，不改变 `CACHE_KEY_VERSION`。

### 2.4 翻译队列

```js
createTranslationQueue({ execute } = {}) → {
  setConcurrency(n),
  enqueueBatch(job) → { jobId, cancel(), dropGroup(group) },
  cancelJob(jobId, reason?),
  dropGroup(jobId, group),
  getQueueStats(),
}
translationQueue // 全局单例
```

```js
job = {
  jobId,                 // 队列分配
  requestId, batchId,    // A2 的提交与批次标识，只用于日志
  groups,                // P6.3 的 group[]，job 执行期间可被摘除
  targetLang, instance,  // 含 apiKey 的完整实例（不落日志）
  concurrency,           // 入队时的实例 maxConcurrency
  controller,            // AbortController，队列创建
  withSlot,              // A2 注入：fn 在全局上游名额内执行
  onDelta(delta),        // 单段批的流式增量
  onItem({ group, text, usage, mode }),
  onBatchDone({ usage, mode }),
  onBatchError(error),
  state, queuedAt, startedAt, finishedAt,
}
```

- **FIFO**：`enqueueBatch` 追加到 pending；按入队顺序启动，不做优先级与页面分组。
- **并发**：`pump()` 在 `running.size < limit` 时取队首启动；`setConcurrency` 只影响之后启动的 pending job；非法值忽略。
- **执行**：单 group 走 `translate`（保留流式与上游 usage）；多 group 走 `translateBatch`（一次请求，按段 `onItem`）。
- **取消**：pending 立即移除并回调 `TranslateError(CANCELLED)`；running 置取消、abort 并立即释放队列名额，执行器稍后收尾时不再回调。
- **摘除 group**：无订阅者的 group 从 job 移除；job 无剩余 group 时取消；运行中已摘除 group 的迟到结果被忽略。
- **统计**：`getQueueStats()` 返回 `{ limit, pending, running, started, done, failed, cancelled, maxRunning }`，只用于日志与测试。
- **测试**：`createTranslationQueue({ execute })` 注入假执行器；单例 `translationQueue` 供 A2 使用。

### 2.5 版本与提示词接口

```js
buildSystemPrompt({ targetLang, template, mode }) → string
hashPrompt(template) → Promise<string>
isDefaultPrompt(template) → boolean
PROMPT_VERSION // 提示词模板与输出格式的结构版本，当前 2
```

## 3. 提示词模板与输出归一

- 提示词是实例上的完整模板（`instance.systemPrompt`，E3 默认值 + 设置页可编辑），本模块只负责展开与兜底。
- 两个程序占位符：
  - `{{targetLang}}`：替换为目标语言显示名（当前只有 `zh` → 「中文」；未知语言回退语言码）。
  - `{{outputFormat}}`：按调用模式替换为程序提供的输出规则。单段（`mode='single'`）要求只输出译文本身；批量（`mode='batch'`）要求输入/输出都是 JSONL，每行 `{"id":"...","text":"..."}`，id 必须与输入一致，不输出解释或代码块。
- 替换时替换全部同名占位符；空模板或缺少模板时回退默认模板（`DEFAULT_SYSTEM_PROMPT`，定义在 E3 的 `registry.js`）。
- 保存校验只保证两个占位符存在、长度与非未知占位符；不限制用户增删防注入语句或风格要求。默认模板包含防注入与逐段独立翻译要求，删除后由用户自行负责。
- `hashPrompt(template)`：模板去首尾空白、统一换行后做 SHA-256（小写十六进制）；换行差异不影响哈希。A2 每个提交计算一次并放进缓存 key，计算失败时本批不参与缓存。
- 输出归一（`normalizeOutput()`）：去首尾空白，剥一层成对引号/书名号等包装，只保留译文；单段与批量共用。
- `PROMPT_VERSION=2`：提示词模板化、占位符与单段/批量输出格式属于新的结构版本；提示词结构、默认模板或语言显示名映射再变化时递增。A4 缓存 key 纳入该值。
- `BATCH_ENCODING_VERSION=1` 由 `batch.js` 定义，P6.2 起进入缓存 key，P6.4 使用。

## 4. 思考参数

- 按实例 `reasoningEffort` 构造 DeepSeek `providerOptions`：

```js
{
  deepseek: {
    thinking: { type: effort === 'off' ? 'disabled' : 'enabled' },
    ...(effort === 'off' ? {} : { reasoningEffort: effort }),
  },
}
```

- `off` 关闭思考且不传 `reasoningEffort`；`low` / `medium` / `high` / `max` 开启思考并传对应强度（`medium` 由 SDK 映射为 `high`）。
- 非法值在 E3 归一为 `off`，不会传给上游。
- 思考模式不设置 `temperature`、`presence_penalty`、`frequency_penalty`（这些参数在思考模式下无效）。
- 页面翻译与设置页测试翻译使用同一适配器函数，不存在两套提示词或参数；批量与单段共用 `deepseekProviderOptions`。

## 5. 错误与提示

上游错误经 `mapError()` 映射为统一错误码，不把原始报错透传给页面：

| 条件 | 错误码 | 提示 |
| ---- | ------ | ---- |
| 缺密钥（调用前短路） | `CONFIG` | 缺少密钥，请先在设置页保存密钥 |
| 外部取消 / 已取消的 signal | `CANCELLED` | 翻译已取消 |
| HTTP 401 / 鉴权类文案 | `AUTH` | 密钥无效或鉴权失败 |
| HTTP 402 / 额度类文案 | `AUTH` | 额度不足或账户欠费 |
| HTTP 429 / 限流类文案 | `RATE_LIMIT` | 请求过于频繁，请稍后重试 |
| 网络错误名 / 网络超时关键词 | `NETWORK` | 网络错误或请求超时 |
| 批量结果与输入不对齐 | `BATCH_ALIGN` | 批量结果缺少该段（由 A2 按段展示） |
| 其它 | `OTHER` | 翻译失败：<原始信息> |

错误码与 `retryable`/`splittable`/`fallbackable` 标志见 [E1-消息协议](./E1-消息协议.md)。

## 6. 日志

- 使用 E4（`src/shared/log/`），不直接调用 `console.*`。
- 单段与批量记录：`engine.request` / `engine.done` / `engine.cancel` / `engine.error`，数据含引擎类型、模型、`reasoningEffort`、`promptVersion`、`promptDefault`、`mode`（`single` / `batch`），批量另带 `batchItems` 与 `encodingVersion`。
- 队列记录：`queue.enqueue` / `queue.start` / `queue.done` / `queue.cancel` / `queue.limit`；批量记录：`batch.request` / `batch.item` / `batch.align`。
- `queue.done` 数据含 `jobId`、`state`、`mode`、`batchItems`、耗时、`usage`、pending/running；`batch.align` 只记缺失/重复/多余/非法行计数。
- 不记录提示词正文与哈希、页面原文、译文、密钥、请求头/体、完整地址；上游原始错误只保留统一错误码与安全提示。
- 日志失败不影响翻译；不因日志改变错误映射、取消或超时行为。

## 7. 边界情况

- **空文本**：单段返回 `{ text: '', usage: null }`，不发上游请求。
- **空 items**：`translateBatch` 直接返回 `{ usage: null }`。
- **缺密钥**：抛 `TranslateError(CONFIG)`，不触发上游调用。
- **已取消**：调用前 `signal.aborted` 为真时直接抛 `CANCELLED`；排队等名额期间被取消时，拿到名额后再次检查并抛 `CANCELLED`，不发上游请求。
- **缺提示词**：实例没有 `systemPrompt` 或为空时回退默认模板；占位符仍由 `buildSystemPrompt` 展开。
- **非法思考强度**：E3 归一为 `off`；适配器再次归一，不把未知值传给上游。
- **流式聚合**：`textStream` 全量消费后读 `usage`；`onDelta` 只在有增量时调用。
- **超时**：单段 `AbortSignal.timeout(AI_TIMEOUT_MS.total)`、批量 `AI_TIMEOUT_MS.batchTotal` 触发中止 → 映射为 `NETWORK`。
- **外部取消**：用户取消触发 abort → 观察并处理 `usage` 的拒绝 → 映射为 `CANCELLED`；日志为 `engine.cancel`。
- **上游异常**：任何非 `TranslateError`、非 `BatchAlignError` 异常都经 `mapError` 归一后重抛为 `TranslateError`。
- **批量空译文**：适配器不特殊处理，按原文回调；A2 对多段批的空译文只失败该段，不写缓存。
- **批量对齐失败**：已解析段落保留在 `onItem` 与缓存中；缺失/重复/未知/非法行只影响未完成段。
- **队列不持久化**：Service Worker 重启后 pending/running 丢失，由 A2 的提交超时兜底；续传归 P9。
- **队列持密钥**：只在内存使用，不落日志、不进帧、不写存储。
