本文记录设置页（C1–C5）的实现细节：布局与断点、导航与路由、各分区的信息与操作、保存模型、状态文案、错误与提示、可访问性与降级。模块划分与依赖见 [项目架构](../项目架构.md) 4.4；布局与控件全部由 Tailwind 与 daisyUI 提供，不再维护页面级样式文件。共享下拉与字段见 [E5-共享展示组件](./E5-共享展示组件.md)。

## 1. 职责与边界

- 设置页只负责「看状态」「改配置」「测试」「清数据」：不调用翻译引擎、不打开缓存数据库、不读凭据明文。
- 读取：`getSettings()`（本页是设置写入方）、`ST_LIST_ENGINES` 的公开字段、`ST_CACHE_STATS`、`chrome.runtime.getManifest()`。
- 写入：通用设置的开关/下拉经 `saveSettings`；实例经 E3 的 `createInstance` / `updateInstance` / `duplicateInstance` / `setInstanceEnabled` / `removeInstance` / `setActiveInstance` / `writeCredentials` / `removeCredentials`；密钥存储经 `setKeyStorage`；域名权限经 `chrome.permissions.request`。
- 实例写入后重新拉取 `ST_LIST_ENGINES`，不在页面本地合并；同一时刻只允许一次写操作（壳层串行）。

## 2. 结构、布局与断点

```text
Options.jsx（壳层：导航、哈希路由、全局数据、写串行、toast、抽屉/对话框）
├─ sections/overview.jsx          概览
├─ sections/instances.jsx         翻译实例
├─ sections/general.jsx           通用设置
├─ sections/test-translation.jsx  测试翻译
├─ sections/data-management.jsx   数据管理
├─ sections/about.jsx             关于
└─ components/                    实例卡片、编辑抽屉、新增对话框、确认对话框、空状态、toast（字段与徽标来自 E5）
```

| 断点 | 布局 |
| ---- | ---- |
| ≥ 1440px | 页面壳层居中，最大宽度 1440px，两侧留白；顶栏内容与内容区同宽对齐 |
| 900–1439px | 左侧侧栏 224px，内容区铺满剩余宽度并保留页内边距；无额外大块留白 |
| < 900px | 侧栏变为顶部粘性横向导航，可横向滚动；内容单列 |
| < 600px | 导航只显示短标签（概览/实例/通用/测试/数据/关于）；卡片单列；抽屉全屏 |

- 页面壳层使用 `mx-auto w-full max-w-[1440px]`；大屏居中，笔记本与平板铺满。
- 状态卡片网格：≥ 1024px 三列（实例卡片两列），600–1023px 两列，< 600px 一列。
- 所有容器允许收缩（`min-w-0`），长文本与 endpoint 使用 `break-words`；360px 不得出现横向滚动。
- 颜色只使用 daisyUI 默认主题语义色；不覆盖主题变量，不新增自定义 CSS、阴影、渐变或关键帧。

## 3. 导航与路由

| 分区 | 路由 | 回答的问题 |
| ---- | ---- | ---------- |
| 概览 | `#/overview` | 现在能用吗？用的是什么？ |
| 翻译实例 | `#/instances` | 有哪些实例？怎么配置/切换？ |
| 通用设置 | `#/general` | 全局行为怎么改？ |
| 测试翻译 | `#/test` | 这个实例现在能翻吗？ |
| 数据管理 | `#/data` | 本地数据占多少？怎么清？ |
| 关于 | `#/about` | 装的是什么版本？权限是什么？ |

- 默认 `#/overview`；非法 hash 用 `history.replaceState` 回退概览，浏览器前进/后退可用。
- 当前项 `aria-current="page"`；翻译实例在有未配置密钥、未授权或不支持实例时显示警示点，否则显示实例数。
- 顶部标题栏：分区标题、全局保存状态（已保存 / 保存中… / 保存失败 / 有未保存更改）、版本徽标、「打开翻译测试页」图标按钮。

## 4. 概览

- 顶部状态摘要按数据给出四种结论：无实例、无可用实例、当前实例不可用（缺密钥/未授权/停用）、正常（`当前使用 类型 · 预设 · 名称`）。
- 六张状态卡片：当前翻译方式、语言、译文缓存、密钥与存储、日志、实例健康；每张带一个跳转操作。
- 警告区按优先级排列：无实例 → 无可用实例 → 当前实例缺密钥 → 当前实例未授权域名 → 存在不支持实例 → 同步密钥 → 提示词仅本机（有 OpenAI 实例时）。
- 快捷操作：新增翻译实例、测试当前实例、清空缓存（跳数据管理并打开确认）、打开翻译测试页。
- 「最近操作」只保留会话内最近一次保存/测试摘要，刷新即清空，不写存储。

## 5. 翻译实例

### 5.1 卡片

| 信息 | 来源 | 缺失 / 特殊值 |
| ---- | ---- | ------------- |
| 类型/预设 | `typeLabel`、`preset` | 不支持类型显示「类型不受支持」 |
| 名称 + 「当前」徽标 | `name`、`activeInstanceId` | 当前但不可用再加「不可用」徽标 |
| 模型或 endpoint | `model`；自定义显示 `host + path`；百度显示「通用文本翻译」 | 未填模型显示「未填写模型」 |
| 凭据 | `requiresKey`、`hasKey`、`credentialFields` | 无需密钥 / 已配置 / 部分配置 / 未配置 |
| 权限 | `permission`（仅 OpenAI） | 已授权 / 未授权，未授权提供「授权访问」 |
| 启用 | `enabled` | 开关直接切换；停用当前实例先确认 |

操作：编辑、复制、测试、删除、设为当前（仅非当前、已启用、凭据完整、域名已授权时可用）；不支持类型只保留删除。卡片不展示密钥长度、APPID 值、请求头/体或提示词正文。

### 5.2 新增

1. 选择类型：OpenAI 兼容（预设 DeepSeek / 自定义）或百度翻译。
2. 名称预填默认名，可修改；校验 1–40 字符、不重名。
3. 自定义预设额外要求 baseUrl 与模型（E3 保存时要求结构合法），校验 HTTPS 或本地回环、无查询参数/片段。
4. 创建成功后关闭对话框并打开编辑抽屉；不自动设为当前（E3 在当前为空且资格满足时自行设为当前）。

### 5.3 编辑抽屉

- 抽屉外壳：daisyUI `modal`（右侧对齐、全高）+ 右侧 `max-w-md` 面板，窄屏 `max-md:max-w-none` 全屏；`role="dialog"`、`aria-modal`、焦点陷阱与 Esc 关闭保留。
- 头部：类型/预设徽标、名称、当前与「有未保存更改」徽标、关闭按钮。
- 基础信息：名称、启用、设为当前、预设切换（切到 DeepSeek 套用预设默认值，切到自定义保留当前配置）。
- 连接（OpenAI）：baseUrl、path、stream、查询参数、静态请求头、域名权限状态与「授权访问」。
- 认证：Bearer / 自定义 Header / Query / 无认证；Header 模式填名称与前缀，Query 模式填参数名。
- 模型：自由输入，最大 100 字符。
- 生成参数：temperature（0–2）、top_p（0–1）、max_tokens（字段名 + 正整数）、思考强度（关闭/强度/预算/开关）、额外参数（path/type/value/enabled）。关闭的参数灰显值并在请求中不发送。
- 高级参数（折叠）：提示词（占位符插入、恢复默认、`n / 2000` 计数）。
- 批次与并发（折叠）：单批段数、批次最大字符数、最大并发数；百度限制 1–20 段、≤ 2000 字符、并发 1–10。
- 百度「接口 QPS」：number 输入，`min=1` / `max=100` / `step=1`，默认 1；帮助文字为「标准版 1、高级版 10、尊享版 100；每个上游请求计 1 次，批量请求按 1 次计算。」；表单校验 1–100 整数，保存写入 `qps`；OpenAI 实例不显示该字段。
- 凭据：只显示字段级「已配置 / 未配置 / 无需密钥」；输入框始终为空，占位「已配置，留空表示不修改」；显示/隐藏切换；清除凭据需二次确认。
- 底部固定栏：取消、保存；保存中禁用并显示「保存中…」。
- 关闭抽屉、Esc 或取消时若有未保存修改，弹出「放弃未保存的修改？」；页面刷新/关闭由 `beforeunload` 兜底。
- 打开期间实例被其它页面修改（`updatedAt` 变化）时显示「该实例已在别处更新」，可重新加载；不静默覆盖草稿。

### 5.4 域名权限

- 权限状态来自 `permission`（后台用 `chrome.permissions.contains` 计算），不写入实例配置。
- 「授权访问」与「保存」都会尝试申请当前 endpoint 的 origin（`https://<host>/*` 或 `http://localhost|127.0.0.1/*`），一次只申请一个域名，且必须在用户手势内。
- 同一 origin 每次编辑只询问一次；拒绝后实例仍可保存并标记未授权，测试/翻译与「设为当前」不可用。
- 授权成功后重新拉取实例列表刷新徽标。

### 5.5 操作反馈

| 操作 | 成功 | 失败 |
| ---- | ---- | ---- |
| 启用/停用 | 行内 toast「已启用/已停用「名称」」 | toast 显示后台原因，开关回到原状态 |
| 设为当前 | 「已切换当前实例为「名称」；只影响之后提交的段落」 | toast 显示原因（缺凭据、未授权、已停用） |
| 复制 | 打开编辑抽屉，提示确认认证与域名授权后启用 | toast 显示原因 |
| 删除 | 列表与计数更新 | toast 显示原因，列表不变 |
| 保存实例 | 关闭抽屉并刷新列表/概览 | 保留输入，显示字段错误或区块错误 |

## 6. 通用设置

| 区块 | 控件 | 保存 |
| ---- | ---- | ---- |
| 扩展 | 启用开关 | 即时保存；失败回滚 |
| 语言 | 源语言、目标语言下拉（共享 `Select`） | 即时保存；显示「当前：源 → 目标」 |
| 密钥存放位置 | 本机 / 跟随账号同步选项按钮 | 确认弹窗 → 迁移（显示「正在迁移密钥…」）→ 成功提示；失败保留原数据 |
| 译文缓存 | 缓存开关 | 即时保存；说明关闭后不读不写、已有缓存不删除 |
| 日志 | 级别下拉（共享 `Select`：详细/信息/警告/错误/关闭） | 即时保存；同步当前页面日志级别 |

即时保存的通用规则：先乐观更新，控件保存期间禁用；成功后显示短暂「已保存」；失败回滚到原值并显示「保存失败，已恢复原值；请重试。」。

## 7. 测试翻译

- 实例下拉列出全部已保存实例（含未启用、未配置密钥、未授权），不支持类型禁用并标注原因；默认当前实例。
- 输入默认 `Hello world`，上限 4000 字符；超限禁用执行并提示。
- 成功结果：译文（可滚动、`pre-wrap`）、实例名称/类型/模型、耗时 ms、token 或字符数、「复制译文」。
- 失败结果：错误码 + 用户提示 + 下一步建议（鉴权 → 检查密钥；限流 → 稍后重试；网络 → 检查 endpoint；配置 → 授权域名/配置密钥/关闭不支持的参数）。
- 未授权时提供「去授权」；结果只保留会话内最后一次，不写存储。

## 8. 数据管理与关于

- 数据管理：缓存开关状态、已用/上限/条数、刷新、清空（二次确认，说明只清译文缓存、不可撤销）；缓存不可用时显示「缓存占用暂不可用，请重试」并提供重试；存储位置说明列出缓存、密钥、提示词与日志。
- 关于：名称、版本、配置版本、缓存数据库版本（`shared/constants.js` 的 `CACHE_DB_VERSION`）、声明权限与静态/可选主机权限用途、隐私说明、诊断信息。
- 诊断信息只含版本、实例数、缓存占用、日志级别与当前实例类型/启用状态；不含密钥、APPID、提示词、原文/译文、完整 URL 或请求头/体。

## 9. 可访问性与主题

- 每个输入有可见 `<label>`；帮助与错误通过 `aria-describedby` 关联；字段错误 `role="alert"`。
- 保存/测试/全局状态用 `aria-live="polite"`；全局失败 toast 用 `role="alert"` 且不自动消失（可关闭）。
- 抽屉与对话框：`role="dialog"`、`aria-modal="true"`、焦点进入、Tab 循环、Esc 关闭、关闭后焦点回到触发元素；危险操作默认焦点在「取消」。
- 状态一律「图标 + 文字」，不只靠颜色；按钮使用 daisyUI 尺寸类（`btn-sm` 默认、`btn-xs` 密集操作、主操作 `btn`）。
- 主题使用 daisyUI 默认 `light` / `dark`，随 `prefers-color-scheme` 切换；不覆盖主题变量，不新增自定义动画。

## 10. 边界情况

| 情况 | 表现 |
| ---- | ---- |
| 设置读取失败 | 内容区错误卡 + 重试，不显示空白或假数据 |
| 实例列表读取失败 | 顶部警示条 + 重试；其它分区仍可操作 |
| 实例被外部删除 | 抽屉自动关闭，列表与概览刷新 |
| 达到 20 个实例 | 新增按钮禁用并提示删除后才能新增 |
| 超过 `storage.sync` 字节上限 | 保存失败并显示后台错误，不写入任何改动 |
| 保存实例后当前实例失效 | E3 按「下一个可用 → 第一个可用 → 无」改选，概览与卡片同步 |
| 权限被撤销 | 卡片与概览显示「未授权」，测试/翻译提示重新授权 |
