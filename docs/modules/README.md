# 模块文档目录

这里放每个模块的**实现级细节**，是 [项目架构](../项目架构.md) 的补充。架构文档只写模块划分与大致流程；具体到某个模块怎么显示、怎么报错、报文长什么样，写在这里。

## 放什么

- 模块的接口与数据结构；
- 页面上的显示结构与样式（例如译文 DOM、错误提示）；
- 与外部服务交互的报文格式（请求字段、响应解析）；
- 错误码与用户可见提示的对应关系；
- 边界情况与已知限制；
- 该模块的修改记录。

## 不放什么

- 模块划分、模块之间的依赖、整体流程 → 架构文档；
- 实现进度与排期 → `docs/PLAN.md`；
- 实现需求与缺陷的来龙去脉 → `docs/demand/`、`docs/bug/`。

## 命名

按模块编号加名称，例如：

- `E1-消息协议.md`
- `D3-译文渲染.md`
- `A3-翻译引擎.md`

模块编号见架构文档 4.1 节。一个模块暂时没有细节可写时，不必先建空文件。
