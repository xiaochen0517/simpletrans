## 1. 职责与边界

- 悬停模式：从指针元素向上解析「当前宿主」：最近的、自身有可译文字且不含块级子元素的标签（任意 HTML 标签）。
- 整页模式：按文档顺序枚举与当前视口上下各半屏相交的段落级宿主，返回归一文本、`index` 与页面内唯一段落 id，供 D5 统一提交与结果回显；不做同文本合并，不分批，不记录上下文。
- 提供文本归一与提取，供 D5 组装提交载荷与悬停单段使用。
- 不发请求、不渲染、不写 storage。
- 不直接写日志；D5 注入 E4 日志入口后由本模块输出 `scan.*`。

## 2. 宿主与标记

| 标记 | 含义 |
| ---- | ---- |
| `data-st-host` | 段落 id，形如 `h<6 位实例标记>-<序号>`（页面内唯一）；同时是 `ST_PAGE_SUBMIT` 的 `hostId` 与结果帧 `itemId` |
| `data-st-translation` | 译文容器（D3 使用）；P4 起嵌套在宿主内部，D1 提取文本与块级子元素判定时必须排除 |
| `data-simpletrans-ignore` | 页面/后续规则可用的忽略标记 |

- `ensureHost(element)`：已有标记复用，否则分配 `h<实例标记>-<序号>`。
- 实例标记在 content 脚本实例启动时生成一次（6 位 `[0-9a-z]`）；序号在同一实例内递增。不同实例的 id 不会相撞，页面上遗留的旧格式 id（如 `h1`）原样复用。
- 段落 id 只在页面生命周期内有效，不持久化；长度 ≤ 64 字符，只含 `[a-z0-9-]`，不包含页面文本、URL 或选择器。
- 段落 id 绑定 DOM 宿主，不绑定文档序号；文档顺序由每次提交的 `index` 表达。

## 3. 宿主判定

任意 HTML 标签都可以作为宿主，例如 `span`、`a`、`button`、`strong`、`em`、`code`、`kbd`、`samp`、`p`、`div`、标题、列表项、`blockquote`、表格单元格与 `summary`。

一个元素成为宿主需要同时满足：

1. 文本归一后非空，且至少含一个 Unicode 字母（`\p{L}`）；
2. 不含块级子元素（子元素计算样式不是 `inline` / `inline-block` / `inline-flex` / `inline-grid` / `inline-table` / `contents` / `none` / `ruby*`）；译文容器 `[data-st-translation]` 不参与该判定；
3. 未命中跳过规则；
4. 不是隐藏内容。

从指针元素向上找**最近**的满足条件的元素；`body`、`html` 不作宿主。因此指针在 `span` 上时宿主是 `span`，在 `button` 上时宿主是 `button`，在 `p` 的裸文字上时宿主是 `p`。

补充：

- 直接文字与块级子元素混排的容器（如 `div` 下既有裸文字又有 `<p>`）不成为宿主：此时裸文字随子块一起跳过，避免译文被追加到子块之后。
- `isBlockHost(element)` 读取宿主计算样式，供 D3 决定 `<br>` 还是 `&nbsp;&nbsp;`；`display:contents` 向上取实际布局；计算样式不可用时才按标签名兜底。

## 4. 跳过规则

| 类别 | 规则 |
| ---- | ---- |
| 脚本与样式 | `script`、`style`、`noscript`、`template`、`svg`、`canvas`、`iframe`、`object`、`embed`、`video`、`audio` |
| 表单与值控件 | `input`、`textarea`、`select`、`option`、`optgroup`；`contenteditable` 非 `false`；`role=textbox/combobox`。`button` 与 `role=button` 不跳过 |
| 隐藏 | `hidden`、`aria-hidden="true"`、自身或祖先 `display:none` / `visibility:hidden|collapse`；折叠 `<details>` 内容（`summary` 除外） |
| 页面声明 | `translate="no"`、`.notranslate`、`[data-simpletrans-ignore]` |
| 已翻译 | 位于 `[data-st-translation]` 内的内容；解析时按 `data-st-for` 归到宿主 |

指针规则：

- 指针落在 `input` / `textarea` / `select` / `option` / `optgroup`、可编辑区、`role=textbox/combobox` 内时直接返回空，不向上找宿主。
- 指针落在 `button`、`pre`、`code`、`kbd`、`samp` 内时正常解析为宿主；这些标签的文字可翻译。
- 指针落在译文容器内时，按 `data-st-for` 返回该译文所属的宿主，而不是把译文当成新段落。

## 5. 文本提取与归一

- 提取时排除译文容器、脚本/样式/媒体子树与表单值控件文字；按钮自身作为宿主时提取其文字，按钮作为其它宿主后代时不计入父段落文本。保留链接、加粗、斜体与行内代码文字。
- 译文嵌套在宿主内部：`extractText` 必须跳过整个 `[data-st-translation]` 子树，否则再次触发会把旧译文并入原文；`hasBlockChild` 同样忽略该节点。
- 归一：去掉零宽字符（`\u200B`–`\u200D`、`\uFEFF`），连续空白合并为一个空格，首尾去空白。
- 归一结果用于 D5 组装提交载荷与后台后续阶段的去重；原文展示不受影响。
- 超长段落（> 4000 字符）仍返回宿主，由 D5 原样提交；长度上限留给 P6.3 / P6.4 的翻译批次，页面侧不拦截。

## 6. 视口段落枚举（P6.1）

**触发**：`ST_START` 时扫描视口附近段落；页面会话期间滚动停止 200ms 后再扫描一次；悬停单段直接对当前宿主提取文本，不走整页扫描。页面加载与 DOM 变化不自动扫描。扫描不改页面文字，只给选中的宿主打 `data-st-host`（复用 `ensureHost`）。

**扫描顺序**

- 从 `document.body` 开始深度优先、文档顺序遍历（子元素逆序入栈，弹出即文档顺序）。
- 选中段落宿主后，它的后代不再作为独立段落；否则继续处理子元素。
- 文档顺序决定段落的 `index`，也是提交数组的顺序。

**段落级宿主**

一个元素成为整页段落宿主，需要同时满足：

1. 不是 `body` / `html`；
2. 归一文本非空，且至少含一个 Unicode 字母（`\p{L}`）；
3. 不含块级子元素（译文容器 `[data-st-translation]` 不参与判定）；
4. 未命中跳过规则；
5. 宿主末尾没有译文容器（`[data-st-translation]` 子节点）；
6. 宿主矩形与「当前视口上下各半屏」相交。

补充：

- 取**最外层**满足条件的元素：`<p>Hello <span>world</span></p>` 的宿主是 `p`；`<div>Hello <p>World</p></div>` 中 `div` 含块级子元素，宿主是 `p`，`div` 的裸文字不单独翻译（与 P4 取舍一致）。
- `td` / `th` / `li` / `h1`–`h6` / `blockquote` / `figcaption` / `summary` 等按同一规则参与。
- 段落内的链接、加粗、斜体、行内代码文字并入该段；`button` 的文字被 `extractText` 排除，选中宿主后按文档顺序单独收集段落内的 `button` 作为独立段落（同样要求视口附近）。
- 纯数字、纯符号、纯 emoji 不成为段落。
- **不做同文本合并**：归一文本相同的多个段落各占一个 `index`、各自进入提交数组；去重由后台后续阶段负责。
- 超过 `MAX_SEGMENT_CHARS`（4000）的段落仍被收集，由 D5 原样提交，不在页面侧拦截。

**扫描跳过规则**（命中即整棵子树跳过，不逐元素向上查祖先）

| 类别 | 规则 |
| ---- | ---- |
| 脚本与样式 | `script`、`style`、`noscript`、`template`、`svg`（按命名空间判断）、`canvas`、`iframe`、`object`、`embed`、`video`、`audio` |
| 表单值控件 | `input`、`textarea`、`select`、`option`、`optgroup`；`contenteditable` 非 `false`；`role=textbox/combobox` |
| 隐藏 | `hidden`、`aria-hidden="true"`、自身 `display:none` / `visibility:hidden|collapse`；折叠 `<details>` 只处理它的 `summary` |
| 页面声明 | `translate="no"`、`.notranslate`、`[data-simpletrans-ignore]` |
| 已翻译 | `[data-st-translation]` 子树；宿主末尾已有译文容器 |

**视口判定**

- `inViewport(host)` 默认 `isElementInNearViewport`：`getBoundingClientRect()` 与「视口上下各扩展 0.5 × innerHeight」后的区域相交，且宽高不全为 0；水平方向不扩展。
- `isElementInViewport(el, marginRatio)` 可用于严格视口（`marginRatio=0`）或自定义余量。
- 只读矩形与视口尺寸，不写样式；视口附近之外的段落不收集，也不进入其后代（行内后代不可能比宿主更靠近视口）。
- 判定函数可注入，jsdom 测试必须注入，否则收集为空。

**段落 id（P6.1）**

- 每收集一段调用 `ensureHost(host)` 取得或分配段落 id；重复扫描同一宿主返回同一个 id。
- 段落内按钮与段落宿主各自分配 id，互不共享。
- 段落 id 是 D5 的提交字段、去重键与结果帧 `itemId`；D1 只负责生成与复用，不维护注册表（注册表在 D5）。
- 页面框架替换宿主节点时，新节点没有 id，扫描会分配新 id；旧 id 的迟到结果由 D5 丢弃。

**上限与性能**

- 单次最多收集 `MAX_PAGE_PARAGRAPHS`（5000）段；达到上限停止扫描并记 `scan.limit`。
- 分片扫描：每处理 `SCAN_CHUNK_SIZE`（500）个元素让出一次主线程；优先 `requestIdleCallback`，不可用时 `setTimeout(0)`。
- 隐藏与跳过状态沿遍历继承；只对通过跳过判定的元素做文本提取与块级判定。

**日志**

由 D5 注入的 E4 logger 输出，不含原文与译文。

| 事件 | 级别 | 内容 |
| ---- | ---- | ---- |
| `scan.start` | debug | `traceId`（随 logger 绑定输出） |
| `scan.done` | info | 段落数、跳过数、耗时 |
| `scan.limit` | warn | 达到 5000 上限，已停止扫描 |
| `scan.error` | debug | 元素标签名（单个元素读取失败，已跳过） |

## 7. 接口

```js
normalizeText(value);      // 归一
hasLetter(text);           // 至少一个字母
extractText(element);      // 提取宿主文本（排除译文、脚本/样式/媒体与表单值控件；按钮自身除外）
isSkipped(element);        // 表单值控件 / 可编辑 / role textbox|combobox / translate=no；按钮与代码不跳过
isHidden(element);         // 自身或祖先隐藏
findContainer(element);    // 向上找最近的文字宿主（任意标签）
resolveAt(element);        // 指针元素 → 宿主；译文容器归位
ensureHost(element);       // 分配/复用段落 id（`h<实例标记>-<序号>`）
isBlockHost(element);      // 按计算样式判断宿主是否块级（D3 选 <br> 或 &nbsp;&nbsp;）
isElementInViewport(el, marginRatio?); // 矩形与视口相交且宽高不全为 0；marginRatio 为上下扩展屏数
isElementInNearViewport(el);           // marginRatio = VIEWPORT_MARGIN_RATIO（0.5）
collectParagraphs(options);            // 视口附近段落枚举，见下
```

```js
collectParagraphs({
  root = document.body,
  maxParagraphs = MAX_PAGE_PARAGRAPHS,
  chunkSize = SCAN_CHUNK_SIZE,
  inViewport = isElementInNearViewport,  // 可注入，jsdom 测试必须传
  yieldToMain = defaultYield,
  logger = null,          // 可选：D5 注入 E4 日志入口，输出 scan.start / scan.done / scan.limit / scan.error
  now = () => Date.now(),
}) → Promise<Array<{ index: number, text: string, host: Element }>>
```

- 只读 DOM 与计算样式，不发消息、不写 storage、不渲染；返回的宿主都已带 `data-st-host`（段落 id）。
- 返回数组按文档顺序排列，`index` 从 0 连续递增；每个元素只有一个 `host`，不带上下文。
- 无 `document` 或根节点不可用时抛错，由 D5 转为 `ST_START` 失败；单个元素读取异常只跳过该元素并记 `scan.error`（debug）。

## 8. 性能与边界

- 悬停模式只解析指针所在的一条祖先链；开销集中在 `closest`、`getComputedStyle` 与一次短文本提取。
- 整页模式是分片扫描：5000 段上限、每 500 个元素让出主线程，只保留与视口附近相交的段落，长页面不整页卡死。
- 视口判定依赖真实布局：jsdom 中没有布局，必须注入 `inViewport`，否则收集为空。
- D2 对指针移动做 80 毫秒节流；命令到达时再按最新坐标复核一次。
- 页面用 CSS 把 `span` 改成块级时，`isBlockHost` 按计算样式返回块级；把 `p` / `div` 改成 `inline` 时返回行内，不依赖标签名。
- 页面替换 DOM 后旧宿主自然失效；不监听全局 `MutationObserver`，动态内容需滚动防抖或再次触发整页翻译。
- 每个 frame 的 D1 只扫描自己的 `document`：顶层文档不进入 `iframe` 子树，iframe 内的文字由该 frame 自己的页面注入实例提取（清单 `all_frames`）；混合内容容器中的裸文字与 Shadow DOM 不翻译。

## 9. 待确认问题

无。任意标签均可作为宿主、按钮/代码可翻译、换行按计算样式判断、整页取最外层段落宿主、只收集视口附近段落、不做同文本合并、段落 id 加实例前缀并兼作结果帧 `itemId`、不记录上下文，均已确认。
